> DCL-025 / D-HW-03。H00 已合并，设备协议尚待批准。本页为 **MOCK / DRAFT** 测试输入与 H10 候选预期。参照 [接口](../../../../docs/design/hardware-api-contract-draft.md)和[安全模型](../../../docs/security.md)。

使用互不相属的虚构家庭甲/乙、设备甲/乙和临时数据库；固定可控服务端时钟。常规语音/Agent 使用本地替身与非敏感成人音频，维护供应商调用计数。观察 HTTP 与错误包络、数据库状态、供应商副作用、脱敏审计及设备状态。表中状态、错误码和责任均待评审。每个情形的真实 H10 验收均未执行。

| S03 提升与 TTS 注入 | 设备尝试创建、管理档案、切儿童模式、解锁、结束或提交任意 text 给语音 | 已认证的禁用动作 403 或原 Web 入口 401；TTS 非法字段 422 | 无角色/会话/账号变化，无语音调用 | 拒绝，排除文本 | 拒绝默认与请求模型 / 无入口或不自动升级 |

| C02 家长与设备翻页 | 同一权威 revision 同时发合法翻页；再用同键同 payload、同键异 payload 重放成功设备请求 | 一次 201、另一 409 SESSION_CONFLICT；同主体同键 201 回执，同键异内容 409 IDEMPOTENCY_CONFLICT | 正常只新增一条事件并增一修订；回放无新增，其他主体不能取设备回执 | 业务事件与设备归因关联，可核对拒绝 | 事务与按代次回放 / 读回后显示正确当前页并更新 revision |

| C04 在途撤销 | 分别在写提交前/后、ASR/TTS/Agent 发出前/后及媒体首字节前/后撤销 | 撤销先提交的受限响应拒绝；已交付/在途字节依边界记录 | 未提交业务无副作用；已提交事实保留，后到语音无交付/可取缓存 | 提交次序、丢弃结果，不收集敏感数据 | 跨边界复核、尽力取消 / 停作业、清缓存，显示授权终止 |
| R01 最小投影与隐私 | 对比各端点字段、日志、反代、错误和诊断；录音取消、低置信、上限及短题拒绝 | assignment 200 仅白名单；取消无 POST；异常 413/415/422 按输入、低置信不自动问答 | 不留原始录音、家长或档案敏感字段，错误不产生无权业务结果 | 最少字段、期限、权限证据 | 审查存储与供应商保留 / 可见录音、取消、清空缓冲 |
| R02 Web 回归 | 家长浏览器既有流程与儿童授权开启、删档案、到期、解锁；对照现有自动化 | 既有 Cookie/CSRF、授权投影、API 错误、报告语义一致 | 既有状态保持，数据库迁移不破坏旧数据 | 既有审计和受控媒体访问按原规则 | 后端/前端跑现有及新回归 / 设备专用头不进入 Web 流程 |

## 本地样本校验

`examples.json` 遵循 `draft.device-authorization` 命名空间。执行 `python hardware/tests/contract/device-draft/validate_examples.py`。校验器只读文件，检查候选路径、动作、错误包络、虚构凭证标记、最小投影、字段类型及样例间的 ID、时序、修订一致性。P01 等测试编号供 H10 关联。矩阵中的认证、数据库、撤销、并发和隐私行为需在 H10 独立执行。不得用 H05 或草案校验结果作为真实授权证据。
