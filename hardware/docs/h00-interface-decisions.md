# H00 硬件接口决策登记

**确认人及登记日期**　黄锦培，2026-11-17。

**状态**　待业务后端与团队评审。适用于 [H00 变更申请](h00-hardware-change-request.md)中的可选扩展 E。

**核对依据**　[API 契约 v0.4](../../docs/design/api-contract.md)、[v0.4 JSON](../../docs/design/api-contract-v0.4.json)及 main `4ee560cf577c34a5084a1f361adcc9d88baa84c8` 的 [FastAPI 路由入口](../../backend/app/main.py)。以下实现状态按源码判断。已注册的业务路由使用 Web 家长会话 Cookie，受保护的家长写操作校验 CSRF。契约中列出的受限儿童角色与未来的硬件设备身份各自需要对应的授权，当前设备联动尚未启用。

## 契约逐项对照

| 契约接口 | main 上的实现与身份 | H00 交接结论 |
| --- | --- | --- |
| API-001 注册、API-002 登录 | 匿名注册及家长登录已实现，登录签发家长会话 Cookie。 | 家长在 Web 操作。设备有独立的凭证签发流程待评审。 |
| API-003 退出 | 已实现 Web 当前会话退出及相关授权吊销。 | 设备解绑和设备凭证撤销需要独立能力。 |
| API-004 档案列表、API-005 新建、API-006 修改 | 已实现，限已认证家长。 | 档案由家长在 Web 管理，设备只获取授权任务所需信息。 |
| API-007 删除档案 | main 无对应路由。 | 保留家长侧职责。后端需确认删除后相关设备授权怎样失效。 |
| API-008 绘本列表 | 已实现家长书架过滤。现行响应的 `coverRef`、`imageRef` 为 `null`。 | 若设备需要书架，需按获准的确切版本投影并确认接口归属。 |

| API-011 创建阅读会话 | 已实现家长创建 `PARENT_CHILD` 会话。 | 候选流程由家长预先创建会话，再给设备授予该会话的权限。 |
| API-012 会话列表 | 已实现家长查询本人会话。 | 设备仅获取获准的会话，保留家长历史列表在 Web。 |

| API-016 提问、API-017 引导、API-018 分支 | main 无对应业务路由。 | 问答、引导和分支联动依赖相关业务能力交付。 |
| API-019 结束会话 | 已实现家长结束会话和小结，支持原键重放。 | 确认设备能否结束会话及应返回的最小数据。 |
| API-020 阅读模式设置、API-021 家长解锁 | main 无对应路由。 | 后端确认设备授权与 `child_grants` 的关系。模式和解锁仍由家长侧管理。 |
| API-022 语音识别 | 路由已实现，默认认证为 Web 家长。当前 multipart 字段为 `file`、`readingSessionId`、`pageNumber`、`revision`。 | 确认设备认证、录音格式和大小时长限制。识别结果用于后续问答，问答能力需另行交付。 |
| API-023 语音合成 | 路由已实现，默认认证为 Web 家长。合成使用服务器核验的事件或会话当前页，返回短期音频地址。 | 确认设备合成访问范围以及授权、会话变化或过期时的处理，保留现有来源校验。 |
| API-024 媒体 | 音频分支已实现，默认认证为 Web 家长，读取时重查来源与权限。契约覆盖图片，main 缺少图片分支。 | 后端和内容负责人确认受控封面及内页资源映射、设备读权限和撤回策略。 |
| API-025 生成绘本、API-026 批准版本 | main 无对应路由，契约属家长侧能力。 | 保留在 Web，设备消费获准的内容。 |

| API-032 健康检查 | 已实现，匿名可读。 | 可检查服务就绪状态。设备是否获准访问资源仍按认证及授权判定。 |

## 待决接口能力

现有契约缺少设备授权签发、设备凭证兑换和授权撤销入口。后端与团队需要确定这些新增接口的方法、路径、编号、请求响应及错误码，并决定会话、事件和媒体能力的复用范围。

| 待决事项 | 需要评审的行为 | 协作评审方 |
| --- | --- | --- |
| 一次性授权与兑换 | 候选方式为家长在 Web 预建会话并签发短时一次性授权，设备在 HTTPS 下兑换独立的限权凭证。决定首轮使用会话级授权，或支持持久绑定与后续换任务。确认有效期、防重放、限流、凭证存储及续期。 | 业务后端、家长端、硬件 |
| 设备任务与资源访问 | 服务端绑定设备、家庭、会话、确切绘本版本和允许的动作。决定哪些既有路由可经设备鉴权后复用，哪些需要受限投影。设备仅持有设备凭证，家长 Cookie 和模型 API 密钥由各自现有流程管理。 | 业务后端、媒体及语音负责人 |
| 解绑、到期与撤销 | 家长可以在 Web 撤销授权。决定会话结束、档案或会话删除、凭证过期、撤销及绘本撤回时的生效时点、旧地址处理和设备缓存清理策略。 | 业务后端、家长端、硬件 |
| 事件与语音联动 | 确认开始、翻页、结束的权限和修订冲突策略，以及录音限制、语音请求失败与重试、问答来源、音频及图片读取规则。 | 会话、语音、Agent 与媒体负责人 |

各项待决事项由黄锦培汇总协作评审方的意见。评审完成后记录接口负责人、采用方案、契约版本及评审结论与链接。联动验收应覆盖授权成功、过期或重复兑换被拒绝、跨家庭/会话/版本访问被拒绝、解绑后旧凭证失效、撤回内容和短期媒体失效，以及密钥与录音脱敏。正式联动依赖后端交付，当前证据限文档与源码核对。
