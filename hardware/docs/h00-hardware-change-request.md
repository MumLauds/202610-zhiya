# H00 硬件设计变更申请

**确认人及登记日期**　黄锦培，2026-11-17。

**状态**　待团队评审。适用范围为 [SRS v0.3 第 6 章](../../docs/requirements/软件需求规格说明书.md#6-可选硬件联动需求不阻塞软件上线)的可选扩展 E，关联 [DCL-025](../../docs/standards/design-change-log.md)。Web 核心流程独立交付。设备联动需另行评审，见 [H00 接口决策登记](h00-interface-decisions.md)。

## 申请与方案比较

申请将立项时的约 4.2 英寸黑白墨水屏与实体按键方案切换为 **Waveshare ESP32-S3-Touch-LCD-4.3C（SKU 33799，无外壳版）**。彩色插图、触摸翻页和录音状态可在同一屏呈现。集成板与厂商示例有助于减少分体器件接线和初次排障工作，显示、触控和音频仍需逐项上板验证。

| 维度 | 立项方案（黑白墨水屏与实体按键） | 申请方案（4.3C 彩色触摸屏） |
| --- | --- | --- |
| 阅读与交互 | 黑白页面、按键翻页和触发录音。静态页面无需背光，更新速度和残影取决于所选面板及刷新模式。 | 800×480 RGB565 彩屏与 GT911 触控。通过屏幕控件翻页和录音，能及时提示录音、上传和失败状态。 |
| 成本 | ESP32-S3、屏幕、按键和音频部件分别采购，另计线材和装配。 | 主控、LCD、触控和部分音频电路集成。另核算扬声器、USB 数据线、运费及演示固定件，按实际 SKU 核对随板配件。 |
| 功耗 | 面板可在刷新后保持画面，整机仍有主控、联网及音频负载。 | 亮屏背光、RGB 刷新、Wi-Fi 和音频会增加耗电，启动或多外设工作时需关注供电压降、掉电复位与温升。 |
| 实现复杂度 | 需适配屏幕控制器、刷新策略、按键消抖和分体音频接线。 | 减少外部接线，增加 RGB 时序、PSRAM 缓冲、GT911 与 IO 扩展器、LVGL 并发和触摸方向的验证工作。 |

板卡依据见 [4.3C 官方资料](https://docs.waveshare.com/ESP32-S3-Touch-LCD-4.3C)和[固定版本的硬件参考](https://github.com/waveshareteam/ESP32-S3-Touch-LCD-4.3C/blob/44e412f08c1e68c0da826bc5f51436f156a02eea/HARDWARE_REFERENCE.md)。墨水屏特性以[同类黑白面板资料](https://www.waveshare.com/4.2inch-e-paper.htm)作为比较参考，立项时未在 SRS 锁定面板型号。

## 风险与取舍

- **采购**　立项预算人民币 250～450 元/台是旧方案估算。硬件负责人按板卡、配件和运输核算样机总额，提供带日期的物料清单与报价。组长确认采购上限和演示所需配件。
- **供电**　首轮按厂商资料使用 USB-C 供电。记录所用电源、亮度及测试负载，测量启动、亮屏待机、连续翻页、联网录音上传、语音播放时的电流及峰值，记录复位、显示异常和温升。功耗上限及是否加入电池供电交团队确认，续航以实测为依据。
- **显示与音频**　RGB565 单帧约 750 KiB，双缓冲约 1.46 MiB，此估算仅含帧像素。H02 要记录缓冲策略及 PSRAM 余量，按板卡修订核验原理图、IO 扩展器、背光、RGB 时序及 GT911。接入音频后再核验显示与外设并行时的刷新、录播和供电。
- **素材与联动**　缺图页使用本地占位及正文。在线媒体、语音问答和同步受设备授权、媒体权限及业务后端交付约束，按接口登记逐项验收。

## HW-01～HW-05 影响与验收

下表均为扩展 E 的拟验收条目，状态为待实板或联动验证。

| 需求 | 影响 | 验收标准及证据 |
| --- | --- | --- |
| HW-01 | 家长选书与任务领取的目标沿用，设备在触屏上呈现获准任务。 | 家长通过 Web 授权一个阅读任务，设备获取正确会话、固定绘本版本和当前页。切换到未获授权版本或另一家庭会话时访问被拒绝。保留脱敏操作记录与服务端结果。 |
| HW-02 | 黑白显示与实体翻页键改为彩色图文及触屏翻页。 | 实板显示测试插图、中文正文和页码，缺图时仍显示占位和正文。点击上一页、下一页能切换正确页面，首页向前、末页向后不越界。记录板卡修订、固件提交及操作视频或照片。 |
| HW-03 | 实体录音键改为屏幕录音控件，增加可见状态及失败反馈。 | 在授权会话中触屏开始和结束录音，看到录音、上传及处理状态。短录音上传后可得到识别或明确的错误反馈，断网或超时能退出录音状态。使用测试语音并保留脱敏日志。 |
| HW-04 | 语音播放目标沿用，使用与 33799 接口匹配的扬声器。 | 播放当前授权页或已核验回答来源对应的服务端音频。音频过期、撤回或不可用时有失败提示。记录实际播放结果和请求标识。 |
| HW-05 | 触屏翻页仍按既有会话进度与事件语义同步，解绑需撤销访问。 | 家长能查看设备提交的翻页或问答记录。同一翻页请求重放仅产生一条记录。解绑后旧设备凭证无法继续读取受控会话、媒体或写入事件。保留服务端记录和拒绝访问证据。 |

**H00 评审交付**　黄锦培汇总组长与需求/设计负责人对板卡、预算、范围和验收条件的意见，以及业务后端对待决接口的意见。评审完成后，将结论和纪要链接补入 DCL-025。

**后续验证**　[H01](../README.md) 的 Windows 构建已通过，实板启动待验收。H02 验证显示与触控，后续阶段测量供电和音频，完成设备接口评审和交付后再记录 HW-01～HW-05 的在线联动结果。
