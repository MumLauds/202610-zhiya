# H07 板载音频设计

H07 为 Waveshare ESP32-S3-Touch-LCD-4.3C（SKU 33799）提供主动录音、短测试音、PCM/WAV 播放及录音回放。H01 启动自检与 H02 显示、触摸继续工作。固件默认使用 H02 页面，H07 页面通过构建配置开启。

## 板级资源

| 资源 | 参考配置 |
| --- | --- |
| I²C0 | SDA GPIO8、SCL GPIO9、400 kHz，与 GT911 和板载 IO 扩展器共用 |
| ES7210 | 7 位地址 `0x40`，驱动常量 `0x80`；输入使能 MIC1/MIC2，I2S0 命名的板上音频网络由 ESP **I2S1** 驱动 |
| ES8311 | 7 位地址 `0x18`，驱动常量 `0x30`；DAC 输出至 NS4150B，再到 SPK |
| I²S | ESP 主机，MCLK/BCLK/WS = GPIO6/44/16，TX 到 ES8311 = GPIO15，RX 来自 ES7210 = GPIO43 |
| 物理格式 | Philips I²S，16 kHz、两路 16-bit slot，MCLK 4.096 MHz，BCLK 512 kHz |
| 功放 | 扩展器 `0x24` 的 EXIO3 高有效，方向寄存器 `0x02`，输出寄存器 `0x03` |

PA_CTRL 的选位来自 V1.1 原理图和锁定音频示例中的 `IO_EXTENSION_IO_3`，交叉核对了托管 BSP 的同一位。微雪产品在线表格曾标为 EXIO4；V1.1 原理图中 EXIO4 属于 SDCS。本轮保持 LCD 背光 EXIO2、触摸复位 EXIO1、SDCS EXIO4 和 USB GPIO19/20 的用途。固件默认按 Slot 0 生成单声道，可在空闲时选择下一次录音的 slot，两路输入各自统计。实际 PCB 修订及物理 MIC 到 slot 的对应关系仍待实板核对。[锁定微雪源码](https://github.com/waveshareteam/ESP32-S3-Touch-LCD-4.3C/tree/44e412f08c1e68c0da826bc5f51436f156a02eea/examples/esp-idf/11_speaker_microphone) · [V1.1 原理图](https://github.com/waveshareteam/ESP32-S3-Touch-LCD-4.3C/blob/44e412f08c1e68c0da826bc5f51436f156a02eea/hardware/schematics/ESP32-S3-Touch-LCD-4.3C-Schematics.pdf) · [产品页](https://docs.waveshare.com/ESP32-S3-Touch-LCD-4.3C)

组件锁定 `espressif/esp_codec_dev` 1.6.2，使用其 Apache-2.0 ES7210/ES8311 实现，两个驱动的时钟表均包含 16 kHz / 4.096 MHz。代码通过自有短超时适配器使用 ESP-IDF 新 I²C 接口，转换组件的 8 位地址为硬件 7 位地址。适配器保留首个寄存器传输错误，即便组件个别方法返回成功。依赖的其他 codec 不参与 H07 构建。两款字体子集来自 Noto Sans SC，许可随 `OFL-NotoSansSC.txt` 保留，H07 字库生成参数在生成文件头部。[Codec 组件](https://components.espressif.com/components/espressif/esp_codec_dev/versions/1.6.2/readme) · [Noto Sans SC](https://fonts.google.com/noto/specimen/Noto+Sans+SC)

## 所有权与时序

- `board_4_3c` 持有 I²C0 总线和扩展器。音频借用总线，只注册及删除两个 codec 设备。扩展器方向及电平都由同一个互斥锁保护，写成功才更新缓存。功放关闭时先写低再设为输出，失败时返回错误并尝试静音及关功放。回到已知状态时重写完整缓存对应的输出寄存器；对总线失联不声称已关闭实物功放。
- 音频工作任务独占硬件及录音缓冲，使用 6,144 B 栈、优先级 4 和深度 8 的命令队列。状态快照及提交门控用短临界互斥锁。UI 每 100 ms 读取快照，提交后即返回。音频任务不持有 LVGL 锁。板级操作可能按 LVGL 锁 → 扩展器锁 → I²C 驱动锁进入，音频路径不反向获取 LVGL 锁。
- I²S 单次 I/O 最长等待 40 ms，块长 160 帧。通过 I²S1 的 TX 侧产生共用时钟。录音期间 TX 只发静音，功放及 DAC 输出保持关闭，RX 独占有效音频数据。播放只启动 TX，RX 不采集。停止或故障先静音、关功放，然后关闭 RX/codec/TX，再按需删除自身资源；共享总线仍服务触摸。
- 播放前将 DMA 描述符预填静音，恢复 DAC 格式和增益后，再使能功放和解除静音。PCM 有 10 ms 首尾淡化及音量上限，默认 20%，上限 40%。DAC 默认 −18 dB，录音回放可选择更高档位。应用完成判断等待四块尾随静音通过 TX DMA 发送队列。因此正常完成基于 DMA 进展，取消则丢弃剩余播放。音量百分比与实际声压需分别验收。

## 业务音频和接口

输入逻辑格式为 16,000 Hz、单声道、PCM16 little-endian。选定的 slot 按明确的低字节在前编码写入 PSRAM。回放解码后把同一样本复制至 TX 双 slot。与现有后端 WAV 归一化格式一致，H07 只做内存内的本地处理。

调用 `board_audio_init` 前先确认显示初始化完成，初始化和释放由生命周期所有者串行执行，释放前停止客户端提交和状态读取。操作返回 `ESP_OK` 表示队列接受，状态和运行结果通过 `board_audio_status` 查询。异步播放的源缓冲在 `pending` 清除且状态离开 `PLAYING` 前须保持可读。PCM 长度以样本计，WAV 输入以字节计。WAV 只接受同规格未压缩的 RIFF PCM，编码工具根据样本数生成标准 44 字节头。

状态依次为初始化、空闲、录音/播放、已录音或可重试错误。同一时间只接受一个录放操作。有效录音 8,000–240,000 样本，达到 15 秒或样本上限自动停止。开始新录音时清除旧有效录音；取消、过短和采集失败不保留本次内容；播放结束、取消和失败保留已有有效录音。静音会将软件采样和 DAC 输出同时置于静音。队列满时返回超时，冲突操作返回状态错误。

## 回放音量与测量

实板版本 `a53417a` 在真实录音回放前后都可正常播放测试音，贴近 SPK 可听见录制内容。录放共用 PA、I²S、DMA、ES8311 恢复和静音路径，因此优先验证实际语音幅度。原 DAC 固定 −18 dB，软件默认 20% 约 −14 dB，默认播放合计约 −32 dB。最大 40% 时合计约 −26 dB。这里的计算是电平比例，实际声压尚待测量。

实板版本 `414b5b1` 的内置测试音与 PSRAM 测试音在 40% 音量下均为 TX Peak 1310、RMS 879 和 8640 帧，两者可听度一致。已测试录音的两次 PSRAM 校验均成功。真实录音最终 TX RMS 仅为 0–59。第三轮选中 Slot 1，交流 RMS 146，Peak 16089，却因全段峰值约束被压到 0.51 倍。第六轮交流 RMS 226 和 Peak 7853 对应约 1.04 倍。

第三版修复了 ES7210 的启动增益顺序。锁定源码中 `es7210_set_gain` 写入寄存器，而 `es7210_start` 调用 `es7210_mic_select` 时使用尚未随前一次设置更新的 `codec->gain`，低 4 位会被重写。现在先启动 codec，再设置有源增益，读回 `0x43/0x44` 的通道使能及 PGA 档位。在启动 I²S RX 之前还核对 `0x11/0x12` 的 16 位 Philips I²S 与非 TDM 模式。平台维持原 I²S1 主机、16 kHz、256 倍 MCLK 和两个 16 位 slot。两路厂商输入一直分别采集，默认录制 Slot 0。是否改默认 slot 取决于同音源、同距离的新实板对照。

ADC 提供 +18/+24/+27/+30 dB，两个增益寄存器的期望低 5 位为 `0x16/0x18/0x19/0x1a`。DAC 提供 −18/−12/−6 dB，锁定音量表为 −95.5 至 +32 dB，每码 0.5 dB。`set_vol` 会根据驱动默认的 3.3 V/5 V 配置作约 +3.6 dB 修正，因此 `0x32` 的期望值分别为 `0xa2/0xae/0xba`。日志记录请求档位、驱动返回、读取值和校验结果。任一关键读回不符时走原有停止与重试流程。ADC 档位在下一次录音启动时生效，DAC 档位只在下一次真实录音回放、功放启用前生效。两个测试音与外部 PCM/WAV 使用 DAC −18 dB 作为参考。两个调试档位只允许空闲时改变，重启恢复默认值。[Codec 1.6.2](https://components.espressif.com/components/espressif/esp_codec_dev/versions/1.6.2/readme) · [微雪锁定音频示例](https://github.com/waveshareteam/ESP32-S3-Touch-LCD-4.3C/tree/44e412f08c1e68c0da826bc5f51436f156a02eea/examples/esp-idf/11_speaker_microphone)

- 回放按 20 ms 帧算去直流后的 RMS。以非尖峰帧的第 20 百分位估计底噪，至少三帧高于底噪两倍才提升。连续低幅语音可以进入补偿，恒定输入、静音和仅有孤立尖峰的输入维持单位增益。该信号判据不区分语音与其他持续变化的声音。
- 峰值至少 1024、峰值/RMS 大于 12 的帧，只从倍率估计中排除。录音数据完整保留，并记录最大峰值的时间 `peak_ms` 和被排除帧数。结合操作时间才能判断是启动瞬态、触碰还是发声。
- 按有效帧平均 RMS 计算倍率，目标 RMS 2200，上限 16 倍（约 +24 dB）。不因某个峰值下调整段增益。超过半峰值上限的采样使用软限幅，DAC −18/−12/−6 dB 对应数字峰值上限 8192/4105/2057，以约束提高 DAC 后的模拟峰值。随后仍按原音量、静音和 10 ms 首尾淡化处理。
- 两个输入 slot、PSRAM 完成读回、回放前源、补偿后、音量/淡化后以及 I²S 实际接收的两路样本都输出聚合统计。整段统计包含样本数、Peak、RMS、交流 RMS、最小/最大值、DC、零值‰、削波计数；TX 帧数包括尾部静音和末块填充。PSRAM 校验比较有效样本数与序列指纹，日志只显示校验结果。
- 清除试听完毕的录音后，可用 `PSRAM tone` 在同一分配和基址写入已知 PCM，再走与录音一致的缓存读取、音量、淡化和 TX 路径。保留录音时该按钮禁用。内置及 PSRAM 两种测试音的数字输出须一致。
