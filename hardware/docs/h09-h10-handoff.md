## H10 后端工作包

| 工作项 | 责任与交付 |
| --- | --- |
| 身份、授权和配对 | **现有业务后端负责人**实现经批准的设备路由、受限 principal 及授权服务；Web 入口沿用 `authorized_db` 的 GUARDIAN + CSRF，核验上游所有权与近期登录。新增专用鉴权，不修改现有 Cookie/CSRF 语义。设备 token 比较摘要，每次读取有效代次、状态、scope 和上游会话。近期登录证据候选加实际交互式登录时间；旧 Cookie 的缺失时间要求重登，无需伪造。 |
| SQLite 迁移与回滚 | **数据库负责人配合后端**评审授权/配对状态（家长/签发 Web 会话/儿童/会话/固定版本/可选 grant/代次/期限）、唯一摘要和事件设备归因、计费收据及脱敏安全审计。暂定拆为配对授权及设备回执两组表，阶段二另增语音占位。活跃/待领设备与会话槽用受事务约束的唯一键，先结算过期尾行再占槽；凭证摘要与一次性码查询摘要用独立用途，消费与发行同事务。说明 FK 清理、老库迁移幂等、并发、备份/可恢复性与部署前后核验。回退先关闭设备入口并使所有设备凭证失效，保留增量表供诊断，若需删列/表另评审并保全已提交业务事实。 |
| 阅读和媒体安全 | **会话/媒体后端**复用 `owned_session`、`SESSION_ACCESS`、`readable_story_version` 中必要并经审计的业务谓词；新增窄投影，不能借用 GUARDIAN/CHILD principal 执行设备请求。以现有事务/修订/幂等设施保存事件，落授权代次归因。扩展媒体 source 及快照、版本和设备代次查验。发起后端实现时重查远程 main 与 Agent #97 的实际落地。 |
| 语音和 Agent（选批） | **语音/Agent 后端**复用 `voice_access`、供应商网关与内容护栏，扩展专用身份及终态来源二次校验。ASR/TTS 增设备级计费占位、限额、取消及未知结果处理。建立严格短题、低可信拦截、已保存 ASK TTS 来源，并和 Web 路径复测。缺少该项批准时保留二阶段关闭。 |
| Web 家长入口 | **现有前端负责人**在本人共读会话增加核对设备、确认及显示一次性码、撤销/重登状态、设备事件来源提示；浏览器端不保存设备 token。桌面先交付内容由评审确认，移动端复用同一 Web 通路或给出过渡路径。验证并行浏览器、儿童模式、退出、跨家庭和 409/504。 |
| 固件适配与联调 | **黄锦培**以 H08 TLS/可信时间和 H04 交互为基础，实现获准的设备 DTO/错误映射、RAM 凭证、单在途事件、离线/回收及公开 DEMO 隔离。后端、前端和安全评审人共同见证 [验收矩阵](../tests/contract/device-draft/acceptance.md)，组长记录批准和发布边界。 |

- **本地结构校验通过**　`python hardware/tests/contract/device-draft/validate_examples.py` 核对 19 个示例、9 条候选路径及 23 个矩阵编号。草案中的相对链接已检查。
- **既有 H05 Mock 回归通过**　`python -B -m unittest discover -s hardware/tests/mock`，43 项通过。本地受限运行无法连接回环地址；放开本机回环访问后重跑通过。测试使用临时资料和 `127.0.0.1`。
- **其余既有回归未运行**　当前主机 Python 为 3.13，已有环境缺少完整 FastAPI、Pillow、multipart 依赖组合，未执行 Web 后端测试。前端与正式接口没有改动，本轮未执行前端回归。
- **H10 验证待执行**　设备凭证和迁移尚无生产实现。新增的授权、跨家庭、数据库、并发、媒体及撤销用例等 H10 后端交付后在隔离环境运行。付费供应商、公网、实际设备、部署和样机安全配置本轮未验证。
- **给后端队友的摘要**　请确认首版能否从现有家长会话派生单设备、单会话限权授权，先交付当前页/翻页/撤销；请重点核对设备 principal 与 Web 路由隔离、签发会话和 grant 的实时失效、媒体/事件来源、计费幂等和旧客户端兼容。表中审批记录齐备后进入 H10 实施。
