## 信任边界

家长浏览器经现有 Secure/HttpOnly Cookie 和 CSRF 向业务服务认证。设备经 H08 校验域名、证书、可信时间后建立 HTTPS，只持有设备限权凭证。本机显示的二维码与家长现场核对用于建立本次配对关联。业务服务是唯一授权权威，按数据库与事件决定状态、归属、范围、期限和访问。语音/模型供应商只从受控服务取得最少必要输入，设备和浏览器均无供应商密钥。设备 Wi-Fi、现场观察者、客户请求字段、固件存储、日志及媒体缓存都位于潜在失密边界。

| 威胁 | 候选保护 | 剩余风险与责任 |
| --- | --- | --- |
| 旁观二维码、短码，抢绑、跨家庭或并发重放 | Web 核对短纹并确认会话。短码一次性、短期，且关联本次随机秘密摘要、家长、会话与设备标识。兑换验证秘密并在写事务内消费。 | 旁观者能尝试诱导家长扫描错误二维码。家长前端明确显示目标与实际短纹，安全负责人评估确认流程和短纹比对强度。物理在场证明和出厂身份仍待评审。 |
| 猜码、刷签发或阻断合法配对 | 用保密键生成短码查找摘要，限制同窗口活跃码碰撞。对来源、领码事务及签发家长分桶，设整个服务上限，可信代理解析来源。错/过期/已消耗响应统一；限流对命中与不存在目标一致，回执不透露家庭。 | 设备 ID 可轮换，不能单独依赖该维度。单桶失败预算、反分布式滥用及共享网络误判由后端验证。 |
| 复制 token、调试口、设备丢失 | 默认 RAM、短期限、单活跃槽、任意请求查撤销。家长能立即撤销失物授权。发布后可另评审每请求持有证明及防重放。 | A 的 bearer 在被完整复制且仍有效时可在其范围内使用。设备 ID、UA、IP 和重发 header 检查不能防止复制。复制风险必须实测并接受，或在上线前批准密钥绑定。 |
| 签发/兑换响应丢失、刷新及重登 | 只按当前登录家长的账号所有权查询最新代次元数据及撤销。短码与 token 只给各自首次响应，原签发 Web 会话始终是设备凭证上游。 | 家长未收到或丢失秘密时须明确撤销原代次并重配。无记录快照不证明在途写入没提交；并发占槽必须串行，重试撤销只操作原代次。 |
| 恶意设备越权、替换业务 ID、滥用报告或家长入口 | 固定授权行衍生 guardian、profile、session、version、grant、scope，客户端字段仅作匹配校验。所有动作逐次检查；与 Web 角色、Cookie、CSRF 分开。 | H10 要覆盖每个入口及原键回放。禁止把 DEVICE 填进未审计的 `role != CHILD` 分支。 |
| 已撤回内容、跨会话媒体、遗留缓存 | 媒体引用按授权代次及来源绑定，服务端读取时复核，返回 private/no-store；私有数据仅停留于授权期间的设备 RAM。 | 客户端失联时服务端无法抹除在用内存或用户已保存内容。H12 验证连接丢失、失效、复位后设备清理。 |
| 付费调用重放、代理超时或儿童敏感内容 | 持久收据、事务扣额、进程崩溃后 UNKNOWN、不同键和同来源限流。调用前、写入及回读复核授权。 | 外部服务已收到的音频/文本或已发生费用无法撤销。后端/语音负责人确认供应商保留政策、计费上限和本地替身测试。 |

### 凭证候选与设备存储

| 选择 | 授权成本与撤销 |
| --- | --- |
| 随机不透明 token（推荐） | 一次下发，持久层存有域隔离的 token 摘要，随机源供给高熵 token；每次查授权行及实时上游，立即停用后续请求。支持多进程一致，需上游 DB 就绪。日志、URL、错误、浏览器存储中无 token。 |
| 签名 token | 验签能独立确认签发，但实时撤销仍需检查授权行/版本或拒绝列表，还需签名密钥轮换、受众与时钟治理。仅依靠短期过期不能满足解绑。 |

建议配对码 8 位、有效期 120 秒，任一授权 15 分钟，最终期限取授权、会话、签发 Web 会话、适用 grant 和其他上游有效期中最早者。可讨论每配对最多 5 次失败、每来源 10 次/分钟、每家长 5 次签发/分钟和服务级限额，结合代理、设备与家庭测试后再定。失败计数达到上限取消 pending；为降低恶意耗尽，记录候选计数策略，未知码及错设备应共享公开失败形态。短码经加密随机源生成，服务端只存独立作用域密钥的校验摘要。有效期、码长、速率、首发证据和具体存储方式均待批准。无需常驻 refresh token。续期由家长按新代次再次确认，旧授权先到期或撤销，无并行有效窗口。

本机在 claim 后及时清除配对秘密与码，token 首发仅放 RAM，重启后重新配对。设备不保存家长账号、口令、Cookie、CSRF 或云模型 API Key。NVS 可用于经评审的非秘密设置和可重置安装标识。若日后支持持久 token，须另评审 NVS 加密与密钥保护、不使用明文故障转储、擦除残留和复位流程。NVS 加密保护写入的条目，Flash 加密保护外部闪存读取，Secure Boot 验证固件来源，调试口限制及签名/升级保护各有职责。当前源码审查未取得样机上这些保护实际开启的证据；默认按缺少抗物理提取保护评估。本阶段保留现有分区和启动配置。H08 必须证明证书链与服务域名校验、可信时钟、请求取消及错误处理。断网或校验失败时阻断私有操作，设备不可切换明文连接。

### 每次授权检查

1. 在设备专用入口认证 Bearer，验证摘要、授权代次、状态、时钟和 scope。拒绝 Cookie 混用，拒绝客户端断言角色、家长、档案、范围。校验当前签发 Web session 所属 GUARDIAN、可用状态及过期/撤销。
2. 同一事务/快照确认授权关联的家庭、儿童档案、会话和固定版本仍有效，会话保持允许的模式与状态，授权范围仍是 Web 家长授权的交集。WITHDRAWN、草稿和待审核版本一律拒绝。已固定的审核后退役版本遵循现有会话读取规则；现有 Web 家长/管理员预览权限不进入设备。
3. 首发仅允许已开始的 PARENT_CHILD 且 `grant_id IS NULL`，设备不能要求转换。若获批 CHILD_SOLO，授权记录必须引用该真实会话的真实 grant 与版本白名单，每次检查 `issued_at <= now < expires_at`、未撤销、同 profile/guardian/版本，服从缩短时限、家长解锁、注销与结算。该扩展需另定独立家长授权来源，因为 API-020 会撤销转换时的 Web session。
4. 读写核对当前页、操作及修订。图片只限当前页，音频只限已校验的页或本次到页的合规事件。任何媒体句柄和收据读取都经过同一检查。设备审计使用已认证主体系，跨家庭和不存在使用同样 404，终止或无效凭证统一 401。
5. 写入占位和最终提交时均复核。无效或不可用依赖时拒绝，不以缓存许可、客户端时钟或重试键补足授权。

## 权限矩阵

“允许”均受认证、现行归属、资源状态及适用 CSRF 限制。设备列为 A 审批候选，待决/拒绝在启用前统一默认拒绝。CHILD 指现行 Web 儿童授权。管理员内容维护能力继续由显式 ADMIN 入口限制。

| 操作 | GUARDIAN | CHILD | DEVICE | ADMIN |
| --- | --- | --- | --- | --- |
| 签发/状态查询/撤销设备授权 | 本人允许（H10 候选） | 拒绝 | 仅可兑换码，拒绝签发/解绑 | 拒绝 |
| 书架 / 详情 | 本人可见书及版本 | 仅 grant 版本 | 拒绝 Web 入口，仅 assignment 当前页 | 仅独立管理目录/审核入口 |
| 建/恢复会话 | 本人，Web 建会话 | 拒绝新建，可读本人 grant 会话 | 拒绝创建，仅固定会话最小恢复 | 拒绝 |
| STARTED / 翻页 | 允许合法流转 | 授权会话内允许 | 拒绝 STARTED；仅允许合法后继，首版禁用在线上一页和私有历史预览 | 拒绝 |
| 提问 | 当前页已确认输入和内容安全 | 当前页受限短题 | 待决，受限短题和家长监督 | 拒绝 |
| 回答 / 反馈 / 引导 | 当前页和事件规则下允许 | 当页受限选项及引导 | 首版拒绝，扩展待决 | 拒绝 |
| 分支 | 已审核本页分支 | 已审核本页分支 | 首版拒绝，扩展待决 | 拒绝 |
| 结束 | 本人可结束 | 授权会话、合法原因 | 首版拒绝业务结束，本地可退出 | 拒绝 |
| ASR / TTS | 当前页或合法来源依接口允许 | 有效 grant 及会话来源 | 待决，短录音及当前来源，拒绝任意 TTS 文本 | 拒绝 |
| 媒体 | 本人可读图片/音频及本人草稿预览 | grant 内可读图片/音频 | 允许当前页图，受控音频待决 | 只允许授权编辑预览图片 |
| 儿童模式切换 / 家长解锁 | 家长设置；在儿童入口用所属家长密码解锁 | 拒绝切换；仅传递独立家长认证进入解锁流程 | 拒绝 | 拒绝 |
| 家庭/儿童档案、续写和账号治理 | 既有本人 Web 权限 | 拒绝 | 拒绝 | 仅既有独立内容管理，禁止冒用家庭身份 |

## 撤销、并发与数据处理

- 家长解绑、本次有效期截止、签发 Web 会话注销/失效、账号失去家长角色、档案删除、会话结束/删除/换版本、版本撤回及适用 grant 失效立即影响授权。可选数据库维护回写终态，安全判断依赖权威实时条件。设备丢失由家长按会话撤销；另一家庭的新配对不能覆盖旧代次。撤销提交后领取、续借、原键重放和新媒体访问都要拒绝。
- SQLite 候选使用一致写锁与条件更新。撤销先提交时，在途写入应拒绝且无新增记录；写入先提交时，既有事件保留供家长核对，向设备回传或续读前复核认证。ASR/TTS/Agent 复核于供应商提交之前及结果保存/返回前。撤销时尽力取消还在执行的请求并丢弃未交付结果。已到供应商的请求可能计费，已开始传输的响应可能有字节在途；服务端在首字节前复核，后续中断能力及分块策略由 H10/H12 验收。
- 单会话一个有效设备授权，同安装标识跨会话同样只占一个槽。Web 可并行写，事务按权威 revision 竞争。沿用原有会话写入和幂等键语义，以授权代次标记设备回执，避免同键取回他方记录。领取与撤销、同键 payload 变化、在途过期和跨家庭争用须有定向竞态测试。详见 [合同草案](../../docs/design/hardware-api-contract-draft.md)。
- 设备阅读前台候选每 3 秒发起 assignment 查询，单次截止 3 秒。服务端撤销即拒绝新请求；健康链路目标 7 秒内发现并隐藏。最近成功且有效快照的请求发起时刻 + 8 秒（单调时钟）为独立硬截止，与 token 到期取较早者。Wi-Fi、有 IP、健康探针与媒体成功都不续期；坏包、DNS/TLS/时钟错误、超时或 503 结束后立即隐藏私有图文，停写、停录、停播、清缓存。后台和重连时必须先查 assignment 才恢复显示，旧 revision、代次与迟到响应不能重新显示私有内容。
- 暂时不可达仅在 RAM 保留未到期 token 和核对原请求所需的非内容状态。到期、终态拒绝或授权变更清除 token、正文/图片/音频缓冲、未上传录音、缓存句柄与旧回执。服务端有撤销事实，家长界面不声明失联设备已收到。设备在线首版只显示权威当前页，公开 DEMO 独立，离线进度标为本地。
- 录音必须由触屏主动触发，界面显示录音与上传，允许取消，超时自动停止；原始儿童音频默认不长期保存。低置信、越界或字段过长不得自动发问。供应商实测使用获准的非敏感成人语音，H10 常规测试使用本地替身与虚构资料。保留已批准业务事件和阅读报告的现有处理，新增安全审计仅记最少主体引用、操作、结果、时间、`requestId` 与适用的供应商状态。日志、反代、追踪、诊断和错误包络不含儿童原文、音频、媒体 key、码、证明、token、密码或账户/儿童全资料。候选保留 30 天、仅授权维护者访问、到期删除，期限和去标识化仍待评审。

### 付费步骤与数据边界（待批）

付费 ASK / ASR / TTS 在调用前持久化发送权和额度扣除；只有确认还处于未取得发送权的 `RESERVED` 才可在故障结算释放预占。已 `DISPATCHED` 的过期执行转 `UNKNOWN` 并保留已扣额度，拒绝迟到工作进程提交及同键、同来源新键再发。跨授权代次和进程的会话总额、分项上限、家庭滚动总额与新键速率共同限制滥用。幂等读取按最新上游授权及当前到页二次校验。

收据只保存作用域、执行状态、规范请求摘要、额度和业务引用等最少字段。ASR 原始音频及转写不落盘，转写最多短时 RAM；TTS 音频也仅短时 RAM，缓存丢失时成功状态仍可查询。仅已批准的 ASK 输出作为业务事件持久化。配对及付费收据的读写错误、审计和反代日志不含秘密、请求键或儿童内容。

逐项验收见 [验收矩阵](../tests/contract/device-draft/acceptance.md)。迁移、责任和批准条件见 [H10 交接](h09-h10-handoff.md)。
