# v7 验证口径

- 合成单元测试覆盖：跨页人物归因证据、故事时间线、当前页和跳过页隔离、回到前页不带入后来对话、原文引用、QUESTION_FORMAT 的边界。改变未读 p4 的结局，p3 的实际生成 messages 保持不变，读到 p4 后才出现差异。
- HTTP 模拟运行和本地测试输出另附。Mock 仅验证所交给生成器的证据和页面状态，不代表 Qwen 的表现。v6 真实样本只用于诊断和配对基线，不计为 v7 新结果。
- 真实 v7 批次独立导出开发、专项和留出。报告区分 API 已尝试、服务端回退、页面样本数、实际模型内容和缺失字段。CLI 不测页面时间。不进行独立核验调用的批次，其核验耗时不可用，不填 0。费用只对显式传入单价的真实生成请求估算，另保存预检用量。
- 盲评要求两位实际独立评审。现阶段没有两份 v7 评分，也不把 v6 的试评迁入。模型质量和泛化能力仍待真实运行及人工评分。
