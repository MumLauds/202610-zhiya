## 复跑

- `python -m unittest discover -v`：后端及证据工具。需先安装 `requirements.txt`。
- `node --test test_browser.mjs test_coreading_browser.mjs`：可在无浏览器、无网络情况下运行模拟测试。可选实际本机 Mock HTTP＋jsdom 集成在启动 Mock 后，设置 `YAYA_V6_MOCK_ORIGIN=http://127.0.0.1:18765`，安装 jsdom 26.1 到本地 Node 环境后复跑；不是实测浏览器绘制时间。
- 使用 README 的 `replay_v6.py` 和 `eval_v6.py`。批量 HTTP 回放只记录后端与 API，不伪造浏览器的展示时间。用实际页面跑出的 JSON 才可填页面耗时。
