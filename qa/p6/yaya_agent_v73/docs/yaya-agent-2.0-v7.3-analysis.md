## REPLY_ONLY 的边界

它是格式投影，不证明正文切题或真实。只有完整解析通过且正文没有可检测到的提问、独立追问在形状/额度/精确重复上失败，才能原样保留正文；不可擅自剪正文或宽松接纳无效协议。丢弃的追问不得进入历史、待答或消耗额度。LISTEN 等动作和 followup 冲突由协议解析约束。语义冲突、未知隐藏追问以及无证事实应由独立诊断确认，不新增未经校准的线上阻断器。允许安全推想和儿童想象，不以字符数或引用次数代替交流质量。
