## 答辩或审查看什么

1. 人物属性归属：书页中的主体、关系、对象与出处作为同一条证据。一条“布鹅有橙腿”不会因为旁边另有孩子，就被数据挂在孩子名下。已有旧案例仍只能说明 v7 留有归属风险，不能当 v7.1 已修复的真实表现。
2. 缺少证据：不能把原文没交代的雨势直接判为「不是毛毛雨」。允许说不知道、表达推测或继续想象。合成样例包括有证、无证、未发生事件与明确想象。真实回复是否实际遵守，待 Qwen 实跑。
3. 正常说话：完整引用里的问号可保留，不改写原始草稿。此次没有放开动作夹带的问句、正文重复追问、额度限制。一个问号也可能问两件事，没问号也可能索要回答，格式保护不等同于语义判断。
