## 独立核验：评价作品，不猜孩子想听什么
核验输入只给已读书页、孩子发言、完整原始草稿（含追问）。另一独立的 6.2 Astra 桌面评审只收到了这 18 条未带参考项的输入；它未看到人工意见、类别、拟定参考或本次事实整理表。它检查两字段，返回逐字疑点和类别；不改写、不调用百炼。不是第二个人，也不是给 Qwen 的真实回归打分。

- 原单人答卷：6 接受、9 拒绝、3 不确定。整体感受不能当成事实真值。R03 的两个动作都正确，“怎么提及了尧宁”是相关性意见；R08 的人评指出语气，但草稿还另有“把想象当书中事实”的错误。R10 被人接受，却在 LISTEN 下继续向明确停问的孩子提问，属于交互错误，不是绘本事实断言。R16 的不可靠主张藏在追问的“两道裂痕”这个前提里。
- 18 条均逐一登记人评原话、意见维度、现有参考状态、拟定问题代码和理由。**真正签署事实代码的数目：0/18。** 书证语义签名：0/28。无需另找第二位盲评人。
- 独立模型桌审：9 接受、9 拒绝、0 弃权；相对暂定诊断标签，8 项事实问题均标出事实类问题，9 项正常表达未被拒，1 项隐藏追问标出。错配属性、错配动作、时间线、想象误拒、隐藏提问各只涉及 1 个专项样本；自然倾听/引用 4 个。具体分子、分母、错误与弃权 ID 在 `v72_fact_metrics.json`。它们是小型成对合成探针，不是泛化率。
- **正式事实漏检率、正常表达误拒率、隐藏提问漏检率均不可计算。** 判据需要真正的人工事实/交互签名；机器一致并不补足这个分母。语气和自然度另外评价，不纳入事实错数。未来如模型弃权或核验缺失，保留单独状态，不当成识别正确。
- 代理方案不是产品的在线核验器：仅在独立桌审上做诊断；尚未验证对陌生文本、动机推测或更复杂推理的实际拦截性能。18 条草稿里没有专门的动机误断对子，不能宣称已解决动机问题。

## 复跑与后续核签
在工程主目录运行 `python v72_fact_audit.py` 可重放保存的桌审结果并重新计算指标，不重新调用模型。运行 `python -m unittest -v test_v72_fact_audit` 可核对候选索引与基线分离、跨页隔离、独立输入及疑点原文绑定。输入/结果、原始诊断样本和既有单人意见保存在 `docs/v72_fact_material/`；这些原始评价以组内审阅为宜。

书证：同一名审核人可在 `v72_fact_book_signoff.csv` 核实逐行理由，保留/提请修改/未决，不自动改变运行时索引。事实：若同一人进行后续类别确认，在 `v72_fact_single_signoff.csv` 的 human_decision 填 USE_PROPOSED、USE_EDITED 或 UNSURE；前两者须签 reviewer，若修改代码则填写 verified_issue_codes，多个以 | 分隔，无问题写 NO_ISSUE。此举是复核，不是另做一轮盲评。另存后用 `python v72_fact_audit.py --human 已核签.csv` 统计，未填或未决保持缺失，不推定为“通过”。
