# v7：绘本证据与跨页记忆

- BookEvidenceIndex 只接收经确认的合成绘本。每条人工整理事件包含页码、证据 ID、人物、动作、对象、状态和本页逐字片段。程序检查引用链；人工仍需负责标注是否真的忠实于原文。没有人工标注的独立留出绘本仍走同一个检索入口，使用原文，不靠模型补写结构化事实。
- 先以真实访问过且书序不晚于当前页的页面求交集，再按当前原话及待答问题的词片重合和最近页排序，最多选四页、累计最多 4800 个原文字符。当前页固定带入；同一批冻结整个上下文构建，而不只冻结系统提示词。三个开发绘本各四页，因此没有丢弃符合范围的历史原文。
- StoryTimeline 仅列所选页与当前页的已读事件。ESTABLISHED 表示有证据的发生，IN_PROGRESS 表示正在推进；角色猜测、角色想象另标。尚未确认的事没有具体事件条目，尤其不把未来事实以 NOT_YET_ESTABLISHED 的名义泄露。孩子想象与模型说过的话保留在带角色、书页、访问轮次和状态的交流历史，不提升为书证。
- 回往前页时滤掉来自该页之后的对话，跳过的书页仍然不可用。书本索引不读取其他会话；现有待答、暂停/恢复及同一访问最多两次追问机制不变。切页动作仍由用户决定。
- 同一北京百炼 Provider、协议 B、温度与 Token 限制。模型自行决定说什么；不发送案例标签、测试答案或期待的动作。唯一通用提示说明证据类型和完成状态的含义。
- 保留原有 QUESTION_FORMAT。诊断明确覆盖合理追问、停问、恢复、引用问句误拦和无问号请求漏检。不用新增标点细则冒充语义核验。独立事实核验尚未实施，因此页面继续标注原始草稿未经独立事实核验。
- 四页窗口不是无限记忆。较长绘本、仅靠语义同义词可找回的证据、误导性故事标注、模型忽略正确证据都不能从工程测试证明解决。留出集仅一次冻结评测，不能作为调参集。

## 盲评

两个独立、顺序不同的离线表，题目先呈现原文与完整当时对话，需要时展开已读证据。分别评绘本理解、跨页记忆、时间线、自然度、上下文承接和倾听能力。逐轮标记可空；不适用的维度选无法判断。不同评审的答卷使用同批键合并，保留逐条分数和差异，映射表不发给评审。开发与留出分开。v6 已发出的原表照常回收，不覆盖；目前没有两份已完成表。
