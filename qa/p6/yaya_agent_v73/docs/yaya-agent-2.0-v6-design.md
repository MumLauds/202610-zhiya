# 芽芽 Agent 2.0 v6｜隔离多轮共读

目标不是把旧规则搬进新 Agent，而是用一次自然语言决策，让模型在连续几轮里接住孩子的想法。实验只用虚构绘本和合成输入，未授权接入真实儿童。

## 复用与扩展

| 责任 | 复用或扩展 |
|---|---|
| 模型连接 | 复用 v5 北京百炼 Provider，Qwen3.8-Flash，协议 B。模型负责接话、追问、倾听；不向模型发送场景标签、判分标准或预写答案。 |
| 书证 | 仅传服务端书页原文，区分当前页和已读相邻前页。讲解/评审事实清单不进生成消息。将未来页留到实际翻页，不用模型猜测填书证。 |
| 记忆 | 限长且只在当前会话；明确发言人、当时真实待答问题、相关页及实际回执。拒绝或迟到的模型草稿仅留证，不作为后轮实际交流。先不做第二次模型摘要调用，避免错改孩子原话。 |
| 交互 | 用户控制翻页与会话；模型动作只改变话题状态。暂停和结束话题不等于结束阅读，孩子可以主动恢复。 |
| 观测 | 分开保留请求与模型原始草稿、服务端回执、浏览器实际展示、独立评审意见。结构检查不是事实核验，未独立核验的文本始终标成合成实验草稿。 |

## 只发合成数据

默认只接受固定脚本与服务端生成的会话 ID，不提供可把任意文字发给云端模型的文本框。配置只由已有环境变量或本机无回显输入提供；不会提交密钥、真实数据、本地运行日志或生产配置。API 成功返回不是一轮体验成功；遇到错误或超时须保留原状。用于验收的独立审阅为离线步骤，未接入线上准入链路，不能声称有生产事实安全保证。

## 泛化不是开发集通过率

12 条样本用于打通系统和查缺，不反馈给生成器、也不是正式泛化结果。冻结提示词、版本、参数、评审量表和开发集之后，由没有参与 Prompt 修改的同学保管新表达或新虚构绘本。重点设置同义改写、原文正反例、改口、停问后主动恢复和跨页指代。以同样路径运行，不在看过留出输出后定制代码；若修通用问题，保留原结果，再用全新未见样本复验。未做盲评不填分，不用模型自评代替。

## 本地接口与状态

- `GET /v6` 启动原型，`GET /v6/catalog` 返回本机虚构读物与脚本。目录数据供演示者选择，不直接发送给模型。
- `POST /v6/start` 创建隔离会话；`POST /v6/page` 由用户显式进入剧本下一轮的书页；`POST /v6/turn` 按会话与零基轮次提交固定原话。API 不接受外部文本。模型不能调用上述路由。已处理的同次访问轮次重放只返回原回执，不再次调用模型。
- 协议 B 的 JSON 字段不变。v6 新增 `PAUSE` 动作；`RESPOND`／`ASK_FOLLOWUP` 映射为 CONTINUE，`LISTEN` 映射为 LISTEN，`CLOSE_TOPIC` 映射为 END_TOPIC。有效期内继续接受孩子新一轮发言。只保留 v5 类型的格式检查与通用追问约束（单轮一问、每页访问两问、完全相同的问题不重复）；不做案例级语义识别。质量评审仍要检查无问号的隐藏提问和语义复问。
- 切页清除待答问题和该页访问的追问计数，保留近四轮带页码的交流。前页原文只在确实访问过且与当前页相邻时另列。首轮无历史，不把上一会话或被拒绝草稿写进记忆。
- 页面使用新会话回执的模式，避免沿用目录页旧的 Mock 标识；五秒分类的浏览器 4.7 秒／服务端 4.1 秒等待阈值不变。浏览器断开并显示自己的回退后结束当前交互，避免让后续继续沿用不一致的对话记录。
- `--record-dir` 生成独立 v6 记录 `v6-evidence.jsonl`，按 session + turn 串联请求、上游草稿与服务回执；页面另导出。上游迟到只记原始数据，不回填展示。核验意见始终与草稿分开。
