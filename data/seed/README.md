# 种子数据

本目录存放系统初始化时需要导入数据库的结构化数据。

## 文件说明

| 文件 | 内容 | 条数 |
|------|------|------|
| `knowledge_items.json` | 领域知识库条目（年龄发展/引导方法/安全规则） | 8 条 |
| `storybooks.json` | 绘本基本信息 | 1 本 |
| `story_versions.json` | 绘本版本信息 | 1 个版本 |
| `story_pages.json` | 绘本每页内容（文字/配图/互动问题） | 6 页 |

## 使用方式

后端启动时读取本目录下的 JSON 文件，批量导入对应数据表。
表结构定义见 `database/schema.sql`。
