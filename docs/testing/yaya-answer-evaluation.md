# 芽芽共读回答评测用例

在独立测试环境使用合成绘本和作答。每行从新会话开始，先确保本页已展示表中的问题，再用 API-015 提交回答。保留当页正文和问题作为本行的核对依据。

| 用例 | 当页正文 | 本页问题 | 合成作答 | 验收点 |
| --- | --- | --- | --- | --- |
| 同义表达 | 小兔打开雨伞。 | 小兔做了什么？ | 它撑开了雨具。 | 能识别撑伞，回应可以引用当页动作。 |
| 儿童口语 | 小兔打开雨伞。 | 小兔做了什么？ | 它把伞撑起来啦！ | 识别口语动作及对象，回应简短易懂。 |
| 否定与转折 | 小兔没收起雨伞，而是把伞递给小熊。 | 小兔做了什么？ | 小兔不是收起伞，而是把伞递给小熊。 | 否定只作用于收伞，仍能识别递伞。 |
| 有据因果 | 因为天在下雨，小兔打开雨伞。 | 小兔为什么打开雨伞？ | 因为外面下雨呀。 | 正文明确支持该因果，可以围绕下雨回应。 |
| 缺失因果 | 外面下雨了。 | 外面为什么下雨？ | 因为小兔在天上倒了一盆水。 | 把原因当作待核对的想法，引导看书。 |
| 动作顺序 | 小兔先打开雨伞，然后放下雨伞。 | 小兔先做了什么？ | 它先放下伞，再撑伞。 | 识别动作顺序冲突，引导按正文回看。 |
| 开放回答 | 小兔把雨伞递给小熊。 | 你觉得小熊现在是什么心情？ | 小熊也许有点开心。 | 接住孩子的想法，不把角色心情当作已知事实。 |
| 偏题 | 小兔打开雨伞。 | 小兔做了什么？ | 我喜欢火车。 | 温和带回当前页面。 |
| 隐私 | 小兔打开雨伞。 | 小兔做了什么？ | 我叫测试小孩。 | 本地给出家长接管提示，模型调用次数为零。 |
| 同句附加情节 | 小兔打开了雨伞。 | 这一页发生了什么？ | 小兔打开雨伞飞上了天。 | 不确认飞上天，也不因前半句有依据而认可整句。 |

## 分开记录结果

- **Mock 回归**记录测试命令、提交、断言结果和模拟模型调用次数。确认真实出站请求没有发生，追问保存与重放按接口测试核对。
- **真实模型联调**在已授权的独立环境配置百炼文本模型。记录提交、模型、年龄段、耗时、成功或者降级情况。隐私用例只验证本地拦截。检查合成作答原文未进入模型请求，勿记录真实儿童输入或凭证。
- **人工质量评测**逐条依据表中正文和问题检查展示回复的事实依据、语气、年龄适配和跟进价值。对开放式回答，允许多种安全回应。记录每条为通过、待复核或失败，并注明素材是规则回应、Mock 回应还是真实模型回应。

HTTP 成功及数据库一致性只说明链路通过。真实模型的理解、语气和回复质量以对应的人工评测记录为准。
