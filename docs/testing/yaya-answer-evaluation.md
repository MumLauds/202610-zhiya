# 芽芽共读回答评测用例

在独立测试环境使用合成绘本和作答。每行从新会话开始，先确保本页已展示表中的问题，再用 API-015 提交回答。保留当页正文和问题作为本行的核对依据。

| 用例 | 当页正文 | 本页问题 | 合成作答 | 验收点 |
| --- | --- | --- | --- | --- |
| 同义表达 | 小兔打开雨伞。 | 小兔做了什么？ | 它撑开了雨具。 | 能识别撑伞，回应可以引用当页动作。 |
| 儿童口语 | 小兔打开雨伞。 | 小兔做了什么？ | 它把伞撑起来啦！ | 识别口语动作及对象，回应简短易懂。 |
| 否定与转折 | 小兔没收起雨伞，而是把伞递给小熊。 | 小兔做了什么？ | 小兔不是收起伞，而是把伞递给小熊。 | 否定只作用于收伞，仍能识别递伞。 |
| 有据因果 | 因为天在下雨，小兔打开雨伞。 | 小兔为什么打开雨伞？ | 因为外面下雨呀。 | 正文明确支持该因果，可以围绕下雨回应。 |
| 缺失因果 | 外面下雨了。 | 外面为什么下雨？ | 因为小兔在天上倒了一盆水。 | 把原因当作待核对的想法，引导看书。 |
| 动作顺序 | 小兔先打开雨伞，然后放下雨伞。 | 小兔先做了什么？ | 它先放下伞，再撑伞。 | 识别动作顺序冲突，引导按正文回看。 |
| 开放回答 | 小兔把雨伞递给小熊。 | 你觉得小熊现在是什么心情？ | 小熊也许有点开心。 | 接住孩子的想法，不把角色心情当作已知事实。 |
| 偏题 | 小兔打开雨伞。 | 小兔做了什么？ | 我喜欢火车。 | 温和带回当前页面。 |
| 隐私 | 小兔打开雨伞。 | 小兔做了什么？ | 我叫测试小孩。 | 本地给出家长接管提示，模型调用次数为零。 |
| 同句附加情节 | 小兔打开了雨伞。 | 这一页发生了什么？ | 小兔打开雨伞飞上了天。 | 不确认飞上天，也不因前半句有依据而认可整句。 |

## 分开记录结果

- **Mock 回归**记录测试命令、提交、断言结果和模拟模型调用次数。确认真实出站请求没有发生，追问保存与重放按接口测试核对。
- **真实模型联调**在已授权的独立环境配置百炼文本模型。记录提交、模型、年龄段、耗时、成功或者降级情况。隐私用例只验证本地拦截。检查合成作答原文未进入模型请求，勿记录真实儿童输入或凭证。
- **人工质量评测**逐条依据表中正文和问题检查展示回复的事实依据、语气、年龄适配和跟进价值。对开放式回答，允许多种安全回应。记录每条为通过、待复核或失败，并注明素材是规则回应、Mock 回应还是真实模型回应。

HTTP 成功及数据库一致性只说明链路通过。真实模型的理解、语气和回复质量以对应的人工评测记录为准。

## 第五轮续作：多轮承接评测

使用 [访次剧本、执行顺序及评审表](../../qa/p6/co_reading_eval/README.md#第五轮续作)，不要把结构检查当成质量评测。三档年龄复用同一合成绘本、同一起始题和同一作答，避免把绘本难度误认为年龄差异。

### 数据流与检查点

1. API-015 在校验身份、会话、页码和修订号后先保存答案和规则回应；模型在事务外选择候选，落库前重新校验执行令牌和修订号。用原始事件键重放时，不应再次请求模型或改变已保存的问答。
2. 当前问题是本次到达后最后一条真正展示的问题。产生追问的 ANSWER 回答的是上一题，不是自己的追问；无追问的 ANSWER 不替换当前问题。通过 API-013 验证刷新，并在分支回到同页后验证旧访次不参与新选择。
3. 儿童作答原文保留在授权服务端，不进入百炼请求。可出的内容限定为本地离散语义信号、当页可核对且筛检过的绘本线索、有限访次摘要及服务端候选。用本地适配器检查合成私密标记以及上一访次标记没进入请求；不导出真实运行的完整请求体。
4. 事实以当页正文为准，只用实际读过的前文辅助理解。情绪、预测和想象要明确为可能，而非情节事实。首轮真实评测不加插画；现有 API-016/017 的授权视觉路径要另外验收，缩略不等于脱敏。
5. 输出先验证允许的编号和策略；返回未允许的编号、无效 JSON 或超时必须保持已保存的本地安全回应。自然收尾只结束讨论，不替孩子翻页、结束会话或写入长期儿童能力标签。

### 两种回应方案

| 维度 | A：审核候选 + 模型选编号（本轮上线候选） | B：受约束自然语言（仅实验设计） |
| --- | --- | --- |
| 自然度 | 模型可按当前线索挑选承接、澄清、想象或收尾，但词汇和句型受候选限制 | 可能更贴合上下文，也可能啰嗦或误认想象。需要盲评，不能因能生成文本就认为更自然 |
| 事实 | 输出事实来自服务端校验后的正文短引文，不采信模型新增事实 | 仅提供同样的安全线索，要求结构化返回 `strategy`、`evidenceIds`、`text`；编号合法不代表自然语言蕴含成立，校验不确定时拒绝并降级到 A |
| 延迟 | 模型只回编号；本地收尾、隐私拦截不需要等待模型 | 额外输出 token 和验证；不追加重试，按 P50/P95 与降级率实测 |
| 隐私与安全 | 不传孩子原文；仅呈现本地允许的候选 | 同一输入边界。仅在合成语料和隔离环境离线观察，不直接渲染给儿童；新增事实、身份信息、指令性文本或越权内容一律拒绝 |

本轮采用 A。B 尚未接入应用，也未做实测；没有可靠可复核的事实与隐私验证前，不启用自由生成。如将来需要出站更多儿童信息，须另提数据流、日志与家长告知方案并先获批准。
