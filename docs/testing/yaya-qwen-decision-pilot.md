# 芽芽共读：Qwen 主导决策隔离试点

## 1. 基线审查

[PR #91](https://github.com/MumLauds/202610-zhiya/pull/91) 的评测对照为远端实际提交 `4e8a605de6def07720f1aca5a964cdc091359f49`。此前本地未推送的焦点与收尾补丁不算对照组的一部分。本试点仅增加 QA 源码及设计与回归，不改变应用启用状态。

API-015 当前路径：`reading_sessions.save_reading_event` 校验会话、页号、修订号和幂等键；先保存儿童作答及规则回应。仅在合格的亲子会话中，`answer_context` 从本次到达之后找最后实际问题、两轮历史、追问记录和已读路径。模型在事务之外调用；`finalize_answer_reply` 重新校验状态和执行令牌，失败时保留已保存的回退。API-013 刷新读回同一事实。API-017 继续用既有引导路径；初始试点不能替换它。

目前 `reading_agent` 在本地用正则、动作/因果判定与当页证据把回答变成有限标签；还生成受控回应和提问候选。Qwen 已可从候选中选择，但理解空间和最终文案由本地规则限定。将候选改成更多关键词不能解决开放交流的覆盖问题；与此同时，脱离可验证证据直接展示 Qwen 的新文案会放大事实和儿童安全风险。

| 环节 | A：现行基线 | B：隔离试点 |
| --- | --- | --- |
| 理解 | 本地先分类，再给模型选项 | 本地仅形成经过批准的离散线索；Qwen 可对当页、问题和最近两轮合成信号提出语义假设，即使本地认为未知；假设与服务端采纳分别记录 |
| 追问 | 按固定意图、已用问题和模板挑选 | Qwen 选择可用焦点并可给新问题草稿；Python 独立排除访次内已问过的语义签名。草稿暂不对儿童展示 |
| 回应 | 模型选择固定候选 | Qwen 可产出自然回应草稿，人工评估自然度；试点的可显示文本仍由限定的安全渲染生成 |
| 状态 | 会话服务读写，访问周期隔离，幂等，最多两条主动追问 | 不变；模型没有翻页、关闭会话、写库、工具调用或权限决定能力 |
| 成本 | 原有 eligible turn 单调用 | 同样最多一次，扩大返回字数但不增加第二次验证调用；无法通过检查时直接本地降级 |

理解边界：如果两句不同的儿童作答在本地被压缩成完全相同的信号，Qwen 就无法还原其中的差异。缺乏决定性语义时输出不确定、引导观察、请家长参与或回退，不伪称懂了。如果以后确实需要把更多语言含义送出，先独立审查本地抽取和可逆识别风险；不得在本方案中直接加入原句、转录、脱敏后整句或历史自由文本。可以考虑本地模型做离散特征提取，但不是这次扩张出站范围的理由。

## 2. 内部协议与数据流

内部决策协议不等于 HTTP API 契约。阶段 B 只实现合成评测模块，不挂进 API-015/017。用一条结构化输出表达理解、策略、动作、关联题与证据。对话状态只交付一个明确的沟通意图（继续读、结束讨论、想再看本页、拒绝继续、普通回答等），不使用可互相冲突的三个布尔位。自报置信度和“有据”声明最多作为分析线索，不能作为校验通过条件。模型选择和事实核验是两回事。

1. **应用内既有边界：** 只有已授权会话才可以读取当前固定版本及实际已读前文。沿用同会话、版本、页面、到达事件四重隔离；新访次重新累计追问。一次读取以当前修订为准；回写前再核对 revision/执行令牌。实验代码不直连数据库、不模拟生产批准。
2. **本地过滤：** 敏感/注入风险本地拦截；原话和音频转录不会进入本共读决策请求。既有语音识别服务不在本试点范围。已有或未来的抽取器仅输出封闭信号，不传儿童自由文本、账号、档案 ID 或日志。证据编号是本次请求内的临时映射；仅限审过的当前页素材及已读背景，后者不能单独证明当页情节。用于模型的题目和证据必须来自经过确认的故事来源，不从儿童答复拼接，也不把参考材料中的指令当指令。试验仅使用无图合成绘本；不触及现存视觉发送路径。
阶段 B 的输入仅限受信的合成素材：一页的确认原文用于本地核验（不整页出站）、最多 4 条安全证据、6 个已审问题及其临时焦点编号、最近两轮离散信号、年段和剩余额度。实现不负责生产身份鉴权、不读取原始作答，也没有接入实际已读前文的提取器；未来接入时前文仅为背景。不能把这一阶段的 fixture/oracle 标签误认为真实语义抽取已实现。

3. **单次决策：** 复用现有 ModelAdapter/ModelGateway 的文本 JSON 模式，由本地 Pydantic 进一步校验。模型不接工具，超时、拒绝、状态不合法、编号错误或重复都不重试。只有受控的通用措辞、核对过的故事事实和允许的问题可以进入可显示结果。
4. **事实与生成稿：** 模型引用已存在的证据 ID 只能证明引用存在，不能证明这段话由证据推出。试点只把自由文案留在成人合成评审环节，禁止渲染到阅读器。生产开放新文案前，需要核实每一条可显示的事实主张（或明确标注为想象）和适龄安全，不确定就用安全回退；这道门槛不允许由同一次生成的自评绕过。
5. **重复检查：** Python 从当前访次已问的问题提取有界语义签名，独立于候选清单携带；换编号且旧题移出候选也可判重。模型不能解除已问 ID、焦点、签名、年龄或额度限制。签名覆盖常见问句，不是通用语义等价检测；人工评审另计没有被覆盖的近义重复。
6. **临时评测数据：** 仅合成剧本、临时无身份的测量行，不导出完整请求或凭证。草稿也视作未审核文本，不落应用日志、数据库、API 响应或用户界面；人工评审如需留档，只保存合成素材与去身份、经检查的结果。

### 当前协议示例（合成）

```json
{
  "understanding": "GROUNDED",
  "action": "ASK_FOLLOWUP",
  "questionId": "q1",
  "focusId": "f1",
  "evidenceIds": ["e1"],
  "proposedConversationIntent": "ORDINARY",
  "proposedUnderstanding": "GROUNDED",
  "proposedResponse": "你注意到它撑开伞啦！",
  "proposedFollowup": "你能在画面上指一指那把伞吗？"
}
```

其中 `e1` 指向服务端已审核的合成当前页证据，`q1` 和 `f1` 绑定在同一份当前访次快照。模型不得创造准入编号；`ASK_FOLLOWUP` 必须使用仍可用的题与焦点，其他动作的题和焦点为 `null`。只有本地已有证据支持当前回答时才允许 `GROUNDED/PARTIAL`。可选 `proposedConversationIntent` 与 `proposedUnderstanding` 都是合成盲评用的模型提议，例如本地 `UNKNOWN` 时可以提出 `IMAGINATIVE`，但服务端采纳值仍可为 `UNVERIFIED`，也不能用提议解锁动作或肯定未经核实的事实。展示路径不取生成稿字段；后者即使通过基本格式和敏感检查，也没有证明内容属实或适龄。策略由动作和理解组合推导，不允许模型自行赋权限。

## 3. 真实验收计划与成本

- 复用 [三年龄同故事剧本](../../qa/p6/co_reading_eval/visit-cases-v2.json) 和原 [36 个单轮用例](../../qa/p6/co_reading_eval/cases-v1.json)，固定 A/B 模型版本、地域、温度、阅读路径、问题起点、送达的语义信号与超时。试点预算为每臂最多 14 次、两臂最多 28 次真实请求，与既有试点一致；先做三龄三轮、三龄想象、明确收尾、错误因果。真实回复若提前结束如实记录，两臂不补抽。可以另记测试素材的信号覆盖率（同信号异意图、无信号和降级各多少），避免把人工构造的正确标签当端到端理解证据。
- A 用现行候选路径，B 用试点决策。相同用例分别记受控可展示结果以及 B 的仅评审草稿。两位独立成人评审看匿名且打乱顺序的合成对话：事实正确及无隐私问题是硬门槛；自然度、适龄性、接话、聚焦和温和纠正分别 0～2 分。假事实、越权、私密原文混入、原始输出进入显示、访次串联、超额度均为硬失败。另记重复提问率（不限相同文字）、无意义追问、正确收尾和不应该收尾却收尾。人工也要判断拒绝和只想继续观察是否混淆。
- 每回合记录端到端耗时 P50/P95、实际派发次数、降级率及原因。把本地拦截（0 次调用）、上游超时、合法但否决、正确收尾分开计；标注样本量和地域，28 次只够做试点，不宣称稳定尾延迟。记录模型请求实际用量；目前项目 ModelAdapter 返回文本与错误，不暴露 token 用量，真实试点用供应商的隔离调用计量或另行在 QA 审核范围内采集聚合用量，不变更生产适配器日志。
- 按[百炼 Qwen3.6-Plus 华北 2 公开价格](https://help.aliyun.com/zh/model-studio/qwen3-6-plus)，低档位示例为每百万输入 token 2 元、输出 12 元。假设 1,500 个输入、320 个输出 token，约 **0.00684 元/次**，28 次全派发约 **0.19 元**，1,000 次约 **6.84 元**。这是示例，不包含额外开销，也不是质量或账单实测；以具体部署范围、目标模型与当前控制台为准。[百炼结构化输出说明](https://help.aliyun.com/zh/model-studio/qwen-structured-output) 仅能说明格式能力，不代替服务端验证。
- 真实试点仅在授权隔离环境、已配专用文本凭证之后运行；只传合成数据。待人工批准且安全与事实门槛通过后，再考虑生产启用及灰度，默认维持已上线的路径，能立即回退。当前 **尚无真实百炼、真实延迟、真实成本和人工盲评结果**。

### 建议的试点通过条件（不是已取得的结果）

1. 先对假事实、不可用编号、重复题、近义重复、跨访次编号、零额度、超时和恶意输出跑 Mock。硬失败不允许被平均分抵消；每次请求的候选展示路径最多一次派发。旧端到端幂等、刷新与两条追问回归照常通过。
2. 真实试点至少获得三档年龄的有效配对。成人评审分别提交独立评分，不将评审讨论后的分数冒充盲评结果。保留分歧以及 A/B 两臂缺失个数；比较事实正确、自然收尾、重复率和安全拒绝率，再看自然度改善。若 B 的优势仅存在于不能安全展示的草稿，不批准替换 A。
3. P95 宜不高于 A 超过 500 ms（试点建议值，之后以业务预算确认），总调用仍受现有回答时间约束。报告真实计费 token、每千 turn 成本、调用率和降级率。不能用 Mock 计时替代百炼网络测量，也不能从 28 次估计稳定 P95。
4. 试点记录行：`case_id, age_band, arm, visit_fixture, model_revision, calls, elapsed_ms, fallback_reason, input_tokens, output_tokens, privacy_pass, fact_pass, semantic_repeat, close_intent, reviewer_1, reviewer_2`。生产风格安全渲染和未审核草稿分别评分。缺少计费数据写 `unknown`，不填 0。

## 5. 复查修订与范围

- **题和证据要绑定。** 通过 Pydantic 只代表形状正常；只有能用本地支持的有界题式与当前已核实分句建立关联的候选，才能出站或成为追问。明确找物必须能在所引证据中核对物件，开放观察不能夹带新事实；一般中文句子、任意改写和自由生成稿不是这个校验器的能力范围。无法确认就不提供该候选。
- **旧题历史单独传给本地判重。** 只有当前访次实际展示的题目用于生成历史签名：展示成功后记录由该题生成的 `followup_history`，在下轮以 `shown_question_history` 提供题号与签名。已知的旧题若不在候选中又缺少对应历史，不允许继续追问。签名不发给模型，也不保存儿童原始作答。本试点仍由 QA 调用方提供访次快照；没有新增数据库表或接入生产事件账本。
- **把提议当作提议。** 本地没有结论时，允许 Qwen 在合成评审通道给出语义假设，分别记假设与安全采纳的结果。影子信号不进入儿童回复、不自动翻页、不改阅读状态。测试“假设能保留”不等于证明猜得对；真实 A/B 要用独立人工标签并统计输入信号碰撞，继续禁止儿童原文出站。

## 6. PR #91 后续优化：语义与验收

本轮以 PR #91 的最新实际头 `b8bfcd2ba7212245c836b243021fc8f0a44a7eaa` 为基线；`4e8a605` 是将实验加入 #91 前的提交。实验仍不接入 API-015/017，不替换生产阅读 Agent。

### 语义输入的边界

仅有 `turn_intent`（是否想继续、留在本页等）和 `answer_relation`（例如未核实/冲突/部分正确），可以保护动作门槛，却不足以知道孩子在哪个细节上犹豫或提出了什么推断。当前问题意图与焦点、最近两轮、已用焦点和可引用证据是不同来源：最近交流不能替当页证据，已用焦点只约束下一次提问。

隔离协议新增可选 `SemanticSignals`，携带有限的表达类型、极性、关联的当前页证据编号及受控焦点编号。编号必须在本地上下文中可解析；字段不接收自由文本。不要把孩子的自由文本当“摘要”送出。把没有可靠抽出的信号标为未知，而不是以更大段原文填补空缺。合成 fixture 中已知的标准答案只用于计分，不应冒充模型可见特征。

**明确的信息损失：**

- 在「小熊为什么把伞递给小兔」这类问题中，「因为它怕小兔淋湿」和「因为它也想玩水」如果都只剩 `UNKNOWN` 或同一个无证据关系标签，模型没有信息区分这两个动机。
- 「它是不是有点着急？」与「我也不知道它在想什么」可以通过表达方式或确定性线索分开，但如果两者最终仍落在同一个局部投影，Qwen 不能凭绘本补回被省掉的话。报告应记输入不可区分、覆盖率和弃权率，不把盲猜算成理解。
- 本轮合成测试可以验证协议能携带更多**已本地提取**的信息，没有实现生产语音／自由回答的普适抽取器，不能据此改变儿童数据边界。

在固定合成桥梁绘本、同一问题和年龄的本地探针里，用记录器调用**现行** `generate_answer_reply`，逐字比较实际出站请求，不调用供应商：两个不同义对中一个被压成完全相同请求（「找条小路绕过去」/「坐小船漂过去」）；两个同义对中一个被分到不同请求（「等雨停了再过桥」/「等雨下完再过桥」）。其余对为「扶栏杆慢慢走」/「等雨停再走」，以及「扶着栏杆，慢慢过去」/「抓住栏杆一点点走」。结果仅是 4 个手标对的见证，不是总体比例，不是新原型提取准确率，也不证明真实 Qwen 模型能力。

### 六种意图分别核验

| 意图 | 可验证的依据 | 不合格示例 |
| --- | --- | --- |
| OBSERVATION 观察 | 开放观察不预设故事事实；找物必须关联本页实际出现的物品，检查否定、假设和引语等 | 文本只写「没出现雨伞」却要求找雨伞 |
| PLOT 情节 | 问的是当前页明确叙述的角色、动作或事件；证据必须能核对具体陈述 | 凭另一页、角色台词里尚未发生的事问“刚才做了什么” |
| CAUSAL 因果 | 同一明确因果关系的原因和结果分别有正文证据 | 事件先后或重复出现不能当成原因 |
| EMOTION 情感 | 仅使用明确叙述的情绪，或围绕本页已核实情境提出**显式推断**；不得把推断说成已知心情 | 主人公做了某个动作就断言他嫉妒 |
| IMAGINATION 想象 | 本页实有角色或事件是起点，问句保留假设标记；不同想象目标可分开 | 将假设写成绘本已发生的事实，或凭空引入故事角色 |
| LIFE_CONNECTION 生活联系 | 以本页已核实情境为起点，问非识别性的生活举例或怎么做；不同主题可分开 | 收集联系地址、学校或把个人经历说成故事事实 |

这些是原则和本轮受支持问法的边界，不表示能验证任意自然语言。必要时宁可不提供候选；对不理解优先保留有证据、简单具体的观察引导。历史排除和预算在本地执行：同一事实的常见改写合并，已问/已答焦点不再追问；`answered_focus_ids` 由可信访次快照单独提供，单纯提到某个焦点不代表已经回答；同意图但不同想象、生活焦点仍可追问。

### 草稿审核和评测口径

`proposedResponse` / `proposedFollowup` 始终只留在合成评审。独立的 `draft_audit.audit_draft()` 用保守的离线分析分段列出可能的事实陈述、推断和假设，再按当前证据 ID 核对；匹配不到、上下文不完整或存在不适龄/隐私风险时标记复核或拒绝。引用 ID 正确不证明文本包含的所有事实都正确；字数和简单句型只作年龄提示，不替代成人判断。该检查不授予任何儿童展示权限。

统计语义重复时同时记 **本地已拦截** 与 **实际提供**，不能把成功拦截当模型本来就不重复。多样性应看不同焦点数量，不看措辞的字面数量。按三档年龄分组，明确闭环/继续观察/拒绝场景的分母；事实拒绝率从已判定的测试候选算，降级率从有效派发回合算，本地隐私拦截单列。Mock 本地 P50/P95 不包含供应商时延。真实百炼调用、计费、自然度与人工盲评必须另表记录。

《访次剧本》结构检查通过后端 pytest 纳入现有 PR→main CI；该检查只验证夹具结构。未推送的新版本只能给本地执行结果，不能借用基线绿灯作为新版本 CI。

### 现有能力与新的封闭映射

| 现有局部信号 | 可用范围 | 不能得出的结论 |
| --- | --- | --- |
| `stance` | 识别固定的不确定、推测和简单肯否；结合显式口语疑问、纠正和假设标记，可形成有限的 `speech_act` | “嗯”不总是肯定；陈述不等于正确；问句不证明前提真实；看不懂的表达保持 `UNKNOWN` |
| `actions` 与 `_actions()` | 可提取已知动词、角色、物品和否定/假设/差点标记；结合闭集语言特征形成 `polarity`。否定与肯定并存时允许 `MIXED` | 不能把开放角色、隐喻、所有省略式或被引语提到的动作识别为实际事件 |
| `evidence`、`evidence_page` 与 `_answer_cue()` | 核对本页片段、判断局部动作是否有依据，回填确有的短证据 ID | 不出站原句、回退片段、角色自由文本或原始结构。指向某条证据不等于肯定它，也不是答对凭证 |
| `order_conflict` | 在可识别动作和已知排序词下检出部分逆序 | 不能恢复任意时态或省略动词的完整时间关系；先不扩展出站字段 |
| `causal` 与 `_causal_parts()` | 识别部分明确因果表达，使用当前页本地检验 | 先后、动机猜测和假设不能被升格为事实；因果还不单独传给本试验 |
| `unverified_detail` | 表明还有无法核实的成分，保守弃权 | “未验证”不是错误，更不是猜测或编造 |
| `color_cue` | 对有限角色/物品/颜色场景取得局部线索 | 不能凭单个颜色词绑定角色，更不能凭文字判定画面可见性 |
| `scoped` / 角色 | 实际代码以 `scoped` 表示问题证据已按角色限定；角色字段在 `AnswerAction.actor`，不是一个通用的 `actor_present` | 只用当前已知证据和焦点映射，不能因答句或相同关键词出现就记录“已答” |
| 重复回答/已答焦点 | 同访次的已问签名、已答焦点由受信 QA 上下文提供 | 提取器没有历史原句，不能独立判断孩子只是重复上一轮；一次证据引用不能写入“已答” |

`extract_semantic_signals()` 仅在本地读取合成回答，先分流隐私/诱导信息，再复用现有局部规则。对外结构保持 `SemanticSignals` 的四个封闭字段：`speech_act`、`polarity`、`referenced_evidence_ids`、`referenced_focus_ids`。动作、因果、时序、否定、纠正的具体对象先用于本地分析；针对这些字段的独立收益暂无真机证据，不增加新的出站文本槽。焦点需要已知的可信映射，冲突或多个焦点共享证据时宁可不猜。结果不写业务事件或自动变更追问额度。

### A/B/C 的可比性和安全门槛

- **A：** 原协议的默认语义投影；**B：** 真实本地提取器产生的封闭信号；**C：** 独立编写的参考信号，仅为诊断参照；不进入 A 或 B。当前参考标注尚待人审核，不冒充人工金标。
- 固定合成故事、问题、年龄档、已读上下文、证据 ID、候选和额度。仅变更各组定义的语义输入。如果动作因为局部信号经过既有安全门槛被过滤，应记录为本地门槛效果，不将它误判为 Qwen 理解。所有组在调用前先执行同一个本地隐私阻断，合成私密句不出站；标注、真实原句、转录、去标识整句、历史自由文和成人评审稿都不作为模型输入。
- 把**提取匹配率**（对独立参考标签；最终由人复核）、**决策准确率**（在真实 A/B 时对模型选择判分）、**交互质量**（匿名双人评审）分开。保留同义分裂、异义碰撞、正确 UNKNOWN 和错误自信的分母；证据/焦点 ID 匹配不当作理解正确。结果切片见报告，少量手标数据不能外推到普通儿童说法。
- 真实调用仍需隔离授权和专用文本凭证。首批至少三年龄档，在相同模型版本、温度、地区和采样参数下比较 A/B，沿用最多 28 次的双臂试点预算；如要真实跑 C，另定预算。记录真实派发次数、token、P50/P95、错误/降级，收齐两位成人独立盲评分后解盲。答复被截断、拒答或超时不能补抽成成功。
- 事实、隐私、同访次去重、降级为硬门槛。所有自然草稿继续只用于合成审核；事实引文必须来自明确叙述，正文的条件、问题和角色引语不能因为出现同样的字就被当作事实断言。合成草稿校验没有“批准播放”结果。
