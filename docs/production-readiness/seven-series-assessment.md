## 当前配对与质量风险

E04 的 28 条正式回包均为严格 JSON 对象且通过本实验的服务端投影。Flash API 14 条样本的最大值 1,219ms，Max 1,750ms。Max 使用额外 schema 及提示，历史对话仍为冻结 Flash 历史。配对用于识别表现差异，无法评价 Max 使用自身历史的体验。

E05 的单份 AI 辅助评分中 Flash 和 Max 各胜 6，2 组相当。自然度 Flash 4.71 对 4.36（14 组），陪伴想象 Max 4.60 对 3.80（5 组），书证 4.83 对 4.67（Max/Flash，6 组）。在 `v73-07/2` Flash 区分了松鼠和小兔，却把回答后半转向推测同一封信，属于意图跟踪回归。Gate 1 设置同题及不同绘本的身份/物件交叉核验。真实页面、独立人工语义和跨作品泛化均独立留门禁。
