# 模型成本对账

应用以人民币微元记账。按配置的输入、输出 Token 单价和上界在模型请求前原子预留。获得供应商 usage 后按输入与输出分别结算，无 usage 保留预留值。既有测试覆盖监护人额度、会话额度、并发预留、日切、超时、缺 usage 与差额，此轮 Docker smoke 检查被撤回授权的请求没有新增账本记录。

真实北京 usage 与应用结算已取得。供应商实际账单及差额核对 **BLOCKED**。前两轮使用北京默认业务空间，第三轮成功结果来自新建的独立测试空间。独立空间的供应商账单尚未取得。获批后，将隔离业务空间的调用窗口按北京时间归档。将供应商的 ID、模型、Token、价格档位、折扣或缓存、可用的用途汇总与应用内部账本核对。不能逐请求对账时，按同一业务空间、模型和计费窗口汇总并记录差异。无 usage、超时、缓存或账单粒度差异应单列。供应商账单独立保留，仓库仅记录允许披露的汇总与指纹。Gate 2 成本签字仍待预算负责人完成。
