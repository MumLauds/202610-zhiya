# 语音接入验收

| 路径 | 实际边界 |
| --- | --- |
| ASR | 录音走既有授权、会话和页面检查；转写成功后以确认的文字提交共读事件 |
| TTS | API-016 的已保存答复文本可以用于合成；失败时文字仍可读取，换页后核验之前的受控媒体失效 |
| 真实 ASR/TTS | 临时云 Staging 合成 WAV、转写确认、真实 TTS 和媒体隔离通过 |
| 真机麦克风与播放 | Android 12 Edge 经 USB 在本机隔离站复验通过。真机录音留在本机测试链路 |

合成测试覆盖 ASR 成功、空转写、供应商故障和确认后送入 Agent，TTS 使用实际保存的答复文字、返回音频、合成失败保留文字、换页后旧音频不可取。由浏览器辅助脚本运行应用语音端点，供应商使用合成响应。真实环境另验慢响应、重复确认、模型回答刷新、翻页以及离开页面时清理录音和播放状态。

本地两组语音探针通过。ASR 由测试端上传合成 WAV、转写后以浏览器确认文字提交；TTS 通过应用权限端点取回合成音频。供方延迟、麦克风交互、重复点击及真实播放另行验收。

## 免 ECS 补充验收

Windows 本机经独立语音 Key 按顺序实调分开的北京百炼 TTS 和 ASR。固定句为「小熊戴着蓝色的帽子」。CLI 两步成功退出，WAV 独立检查为非静音 2.72 秒、24 kHz、16 位单声道 PCM，130,604 字节。终端 ASR 逐字文本未归档。

Android Edge 实际完成麦克风录音、上传、确认转写并提交提问。手机的 ASR 与 Agent 回复由本机合成服务提供。使用上一项真实百炼生成的 WAV 验证手机加载并触发 playing，随后结束阅读。未将真实设备的录音发送给供应商。本机组装流程和独立站的供应商联调分别保留。

## 2026-11-28 语音鉴权根因与同站复验

Windows SSH 启动器已修正。原启动器的回车处理参数在远端被解析为删除字母 `r`，导致语音 Key 改变。修正后通过校验验证同一凭证从输入传到容器。北京默认业务空间的 ASR 与 TTS 在 Windows 本机和临时 ECS 直连均返回 200。实际应用对合成 WAV 完成关键词识别并取得 522,284 字节受控 WAV，跨账号访问为 404。此结果为同站合成语音供应商验收。证据指纹见 E25。
