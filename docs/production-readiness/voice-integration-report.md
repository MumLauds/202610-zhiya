# 语音接入验收

| 路径 | 实际边界 |
| --- | --- |
| ASR | 录音走既有授权、会话和页面检查；转写成功后以确认的文字提交共读事件 |
| TTS | API-016 的已保存答复文本可以用于合成；失败时文字仍可读取，换页后核验之前的受控媒体失效 |
| 真实 ASR/TTS | BLOCKED，待独立 Staging 和合成专用语音配置 |
| 真机麦克风与播放 | BLOCKED，待合成语音、真实设备和云端访问 |

合成测试覆盖 ASR 成功、空转写、供应商故障和确认后送入 Agent，TTS 使用实际保存的答复文字、返回音频、合成失败保留文字、换页后旧音频不可取。由浏览器辅助脚本运行应用语音端点，供应商使用合成响应。真实环境另验慢响应、重复确认、模型回答刷新、翻页以及离开页面时清理录音和播放状态。

本地两组语音探针通过。ASR 由测试端上传合成 WAV、转写后以浏览器确认文字提交；TTS 通过应用权限端点取回合成音频。供方延迟、麦克风交互、重复点击及真实播放另行验收。
