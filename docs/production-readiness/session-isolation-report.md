# 会话隔离验收

| 边界 | 自动化证据 |
| --- | --- |
| 账号与档案 | 应用交互测试覆盖监护人和儿童档案校验。Docker smoke 增加第二监护人访问他人会话应返回 404 |
| 会话、版本与页面 | 仅允许当前会话、同一绘本版本和当前页面访问中的助手回复用于续谈。翻页后回看按访问边界重新计算 |
| 已读与未读事实 | 依据已访问路径、当前页和已审核证据。本轮回归继续覆盖未读页、正文指纹、人物属性及想象来源 |
| 撤销模型数据授权 | Docker 阶段移除输入白名单并重启应用，原 2.0 Session 仍固定版本，返回 DEPENDENCY_UNAVAILABLE，模型费用账本新增记录为零 |
| 停用 Agent 2.0 | 新会话回到旧链路，已有 2.0 会话以 2.0 安全本地策略继续 |

同页最多携带两条此前已展示的合格助手回复。测试验证跨会话、历史孩子原文及回复中完整复述该原文的情形不能进入请求。真实 Staging 的跨账号、跨 profile、跨不同绘本和授权撤回仍待在获批环境执行。

修复版真实 API 样本中，首次前进翻页前的 9 个第一页请求均未携带第二页纸风车内容。来源题只用本轮脱敏后的短语，在同版本、同会话和本次页面访问的已有记录中确认是否出现过；跨会话和重新进入页面的用例均不会携带该线索。
