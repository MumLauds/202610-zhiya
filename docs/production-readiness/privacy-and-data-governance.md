# 隐私与儿童安全

**当前决定** 合成数据可用于独立 Staging。任何真实儿童数据进入新链路前，须通过 Gate 2 并取得家长授权、产品审批、专业法律意见和供应商处理留档。

## 数据清单和最小用途

| 数据 | 应用保留建议 | 供应商传输与删除 |
|---|---|---|
| 家长账号、登录 Cookie、密码、家长授权编号、儿童档案明细 | 账号/认证服务处理。模型仅在必要时获得适龄年龄段 | 不出站。撤权即时生效。账户/档案删除由现有业务和审核后的生命周期处理 |
| 绘本、版本、实际进度和分支 | 固定作品版本、授权与已读页。家长查看阅读记录 | 文本推理仅接收已审核、与问题相关的正文和线索。去除内部主键、私有媒体 URL、未读内容。私人原创出站需单独批准 |
| 儿童文字和 ASR 转写 | 确认后的必要作答按正式阅读事件管理。未确认转写用完即丢弃 | Gate 2 前仅合成数据。通过独立许可的亲子会话才可发送最小化的本轮表达。报告、视觉和 ASR/TTS 分别审数据合同 |
| 麦克风原始音频、TTS 媒资 | 采集有明确设备授权。原音频处理结束即清理临时副本，允许的 TTS 缓存绑定会话/授权/有效期 | ASR 经独立供应商用途与同意审查。音频不进文本模型。旧授权撤销后下载与播放都失效 |
| Prompt、原始输出、最终回执 | 模板版本及校验结果可留元数据。原始请求/输出默认不落日志和诊断库。通过的最小回执按阅读记录管理 | 原文片段、年龄段、受控上下文是拟批准的文本出站范围。供应商端保留和删除要走确权 |
| 运行日志、调试和实验文件 | 日志记录关联编号与失败类别，禁用请求体、Header、录音和完整对话。建议试运行结构日志 30 天自动清理，经审批后启用 | 合成实验日志专库。异常调试只用合成或经批准脱敏数据。角色 RBAC、访问留痕、导出有审批。告警消息不带原文 |

技术方案建议把受控家庭试运行数据的保留设为目的完成即删除。启动 Pilot 前由数据负责人确认具体业务保留期、法定例外、备份最长窗口及删除 SLA。建议把未确认文本和上传临时文件默认清理放在请求结束分支。用最小集验证正常、超时、断开、退出及进程重启。禁止全量生产抽样进入 QA。撤权后的恢复应重放删除记录并避免备份重新公开。

## 阿里云与地域

百炼公开说明解释调用数据会按相关要求保存，并声明不会将客户数据用于模型训练。接入地域、数据存放地域和推理部署范围需分别确认。公开说明未给当前账户的逐项保留期和主动删除 SLA，需由采购/运维保存适用协议及控制台配置或供应商书面回复。项目须核对北京专属业务空间、实际推理地域、是否开启日志回流、必要分包方、备份/事故通知、请求与输出删除入口及执行证明。合成出站授权只覆盖相关实验。 [百炼隐私说明](https://help.aliyun.com/zh/model-studio/privacy-notice) · [百炼服务协议](https://terms.alicdn.com/legal-agreement/terms/common_platform_service/20230728213935489/20230728213935489.html) · [百炼服务特别说明](https://help.aliyun.com/zh/model-studio/bailian-service-notes) · [地域与服务部署范围](https://help.aliyun.com/zh/model-studio/regions)

若香港 ECS、日志/备份或支持人员能接触内地儿童个人信息，需评估完整路径及是否属于跨境提供。百炼选北京不覆盖 ECS、Cloudflare、语音、支持和日志的全部路径。没有专业意见前，Pilot 的真实儿童请求不得进入香港环境或其他未批准区域。

## 法律与平台事项

- 个保法第 28–31 条涉及不满 14 周岁信息、敏感信息、监护人同意及专门处理规则。适用的单独同意、告知字段、影响评估及记录留存由法律专业人员确认，关注第 38–40、47、55–56 条。对知芽、百炼和其他接收方的角色及各用途建立记录。 [个人信息保护法](https://www.samr.gov.cn/zw/zfxxgk/fdzdgknr/bgt/art/2023/art_f374e8245320413181742e6d1baf4366.html)
- 家长应能查阅、撤回、申请更正或删除。告知列明必要字段、作品/问题片段如何处理、存放地、接收方、目的、保留和渠道。AI 入口可关，基本阅读可继续。核对适用于服务形态的儿童规则、生成内容标识和备案等义务。 [未成年人网络保护条例](https://app.www.gov.cn/govdata/gov/202310/24/508651/article.html) · [儿童个人信息网络保护规定](https://www.moj.gov.cn/pub/sfbgw/flfggz/flfggzbmgz/202101/t20210105_146377.html) · [生成合成内容标识办法](https://www.cac.gov.cn/2025-03/14/c_1743654684782215.htm)

## 儿童交互与人工接管

输入守门识别隐私、越界指令、危险行为、色情暴力及求助。保留正常想象、情绪表达和阅读提问的正例。输出独立守门并拒绝制造事实、收集身份或给危险建议。危险/求助返回简洁、安抚且指向可信成人的本地提示，家长可以主动发起人工处理。值班查看脱敏事件，只有获授权的处理人方可访问必要的业务记录。安全依赖故障时关闭生成，旧阅读仍可用。

前端清楚提示芽芽的 AI 身份，提供暂停和退出。避免要求保密、独占关系、诊断儿童、强制评价或机械追问。删除回执的测试必须涵盖 SQLite、执行记录、缓存、媒资、备份恢复和供应商工单。发生异常时先停止新调用、保留必要审计、由数据负责人决定处理和通知。

## 候选实现边界

2.0 会话归属与百炼出站分别授权。部署方只在具备经过审批的数据治理与监护人授权记录后，以 `guardian_id:child_profile_id` 将获批的监护人与儿童档案配对加入 `YAYA_AGENT2_INPUT_ALLOWLIST`。同账号的其他儿童档案需要各自授权。名单为空时用户表达留在本地。撤销授权时移出对应配对并按环境发布程序重载。儿童凭证、儿童独立阅读和私人原创绘本走本地路径。

合规的亲子会话可把完成安全检查和最小化后的本轮表达作为普通 user 内容发送。实际账号 ID、档案 ID、家庭地址、凭证、语音、私有绘本和历史原话均排除。可明确移除的姓名、联系信息等仅保留剩余阅读内容。地址、凭证、暴力等高风险内容触发本地交接。脱敏或阻断的原输入不写入 2.0 交互事件，不记录在日志。其他由本人家长确认的安全作答仍受现有授权历史规则约束。

代码覆盖已知敏感模式。真实儿童启用仍待独立同意记录、漏识别复核、撤回与删除、百炼留存与地域治理联合审批。真实供应商验证使用虚构绘本和合成儿童表达。 [候选服务](../../backend/app/services/yaya_agent.py)

## 最终审查的隐私回归与范围

用于出站的输入先做 Unicode 归一化检查及敏感分句判定。中英文姓名（含长中文姓名）、多语姓名表达、手机号、邮箱、家庭地址、学校、证件和账号都在合成回归中。识别到敏感内容后只考虑末尾可独立理解的绘本问题，家庭地址、证件和账号场景还要求明确的绘本指向。配置凭证、伤害和注入信号直接触发本地保护。

新增交互回归同时截获合成百炼请求正文、检查 API-015/016 的 SQLite 事件及日志。安全书问可恢复，脱敏前原文和身份标记未出现在测试的出站、事件或日志中。已覆盖样式不能代表所有方言、拼写、非结构化地址或无提示的姓名。真实儿童启用仍须经代表性语料的漏识别和误拦截人工复核、逐档案监护授权与撤回验证、供应商处理和数据留存/删除审批。
