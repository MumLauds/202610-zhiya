# 运行观测与成本

## 当前能力与差距

[网关](../../backend/app/model_gateway.py) 使用共享 HTTPX 客户端、无传输重试、总时限与响应字节上限。网关区分鉴权、限流、服务异常、超时和无效响应，应用日志含调用编号、结果和耗时。生产 [适配器](../../backend/app/adapters/model.py) 只返回 TIMEOUT/API_ERROR 及成功文本，未暴露 Token 数据或模型版本指纹。[配置](../../backend/app/config.py) 从环境取 Key。正式仓库默认模型名为 `qwen3.6-plus`。2.0 目标显式设置北京 Flash，核对 endpoint/Key 所属空间、返回模型 ID、Prompt SHA-256、应用发布号与内容版本。记录安全标识或凭证版本，禁止打印 Key、Header 和完整上下文。

| 观测分类 | 典型依据 | 业务处置与告警 |
|---|---|---|
| API_CONNECTION_ERROR | DNS/TLS/传输 `RequestError` | 标记线路或连接问题，安全回应。连接失败比例告警 |
| API_TIMEOUT | 内部总时限或上游超时 | 取消未完成工作，保留已落库事件。单列模型超时与浏览器截止 |
| API_HTTP_ERROR | 401/403、429、4xx、5xx，记录可见 status | 401/403 运维处理配置，429 控制流量，5xx 安全降级。不回显供应商正文 |
| MODEL_OUTPUT_INVALID | 可响应 HTTP 但 JSON、结束原因、为空、字段或长度错误 | 安全回退，区分 schema/截断/空输出的内部原因 |
| QUESTION_FORMAT | 正文/追问格式、额度、重复或隐藏索答 | 独立统计。追问有问题而正文安全完整时走 REPLY_ONLY |
| DEPENDENCY_UNAVAILABLE | 配置、DB、书证或守门不可用 | 缺守门禁止生成。既有错误码按 API 合同。前端可继续基本阅读 |
| CLIENT_DISCONNECTED | 已确认 ASGI 已断开或请求取消 | 停止未出站任务。已出站则记录可能费用，保存可查询的终局。不改变媒体/对话上下文 |

内部分类可另增 `SAFETY_BLOCK`、`BUDGET_LIMIT`、`LATE_DISCARDED` 和 `IDEMPOTENT_REPLAY`。HTTP 业务错误保留 401/403、404、409、422、503、504 的既有语义。成功保存后的模型回退可正常返回回应，用户提示不得等同数据库失败。

## 指标和取证

- 结构日志建议包括 `requestId`、安全的内部执行 ID、模型 ID/地域标记、Agent/Prompt/发布版本、低基数的失败类、投影、HTTP 状态、Token 用量和阶段耗时。账号与会话配额留在授权存储中，通过短期假名关联。禁止在指标标签放 session、原始事件、IP 或文字。
- 试运行分别记录 API P50/P95、后端从读权限到落库时间、浏览器确认到可见回执时间和 TTS 首音。报告 N、浏览器、环境、时间窗、超时/取消、成功、回退、质量失败，样本稀疏时保留原始分布。1 次合格请求与重放、保底、无效和掉线的分母单列。
- 面板监控任务积压、SQLite busy、进程/连接池、磁盘、水位、媒体资源清理与告警到达。异常触发后可用脱敏关联追踪。测试告警包含鉴权突增、429、超时、超预算和浏览器恢复失败。

## 费用与限流

调用前按部署时费率、允许上下文长度和输出最大 Token 估算预留，原子检查全站日预算、监护人日配额、会话配额与并发。幂等执行首次占位才预留。发送后用供应商 usage 结算，未返回 usage 时记录未知并暂保预留到对账，不记成 0。按模型、地域和日期回查账单。ASR/TTS 单列。价格发布前重验，实时账单优先于实验估算。 [北京 Flash 计费](https://help.aliyun.com/zh/model-studio/qwen3-8-flash)

试运行参数建议从每账号每日 40 次生成、每会话 20 次、每会话 1 个进行中调用起。全站日限额建议初始 ¥10，预算负责人签字后才生效。80% 告警，100% 拒绝新模型调用，文字、翻页、小结的安全路径和本地回应继续。普通对话避免不必要的模型调用，达到限额时给家长温和提示，保底不耗新的模型额度。每请求默认 0 自动重试，重试需能证明未出站或与同一执行关联。

## 候选实现与计费边界

2.0 的日志以服务端 Request ID 关联 HTTP 时延、模型标识、Prompt SHA-256、供应商请求 ID、Token Usage 和分类结果。原文、对话和草稿留在请求处理范围。预算表用 HMAC 用户和会话标签，按 UTC 日预留保守上限，失败也保留预约额避免低估。供应商无实时账单字段时按预算上限执行。实际价格、租约故障、保守预约与账单偏差、告警阈值以及线上 P50/P95 仍需 Staging 验证。 [计费预约](../../backend/app/db/yaya_agent.py)

## 审查后的分类口径

2.0 的 API-016 技术回退将实际分类写入 AgentResult.strategyType 和 agentReceipt.reason。桌面回执和移动策略标签沿用同一分类。模型日志以服务端请求 ID 记录相同 reason 和决策，脱敏详情、供应商请求正文和原话不进入日志。REPLY_ONLY 仍可展示有效正文，其 reason 保留 QUESTION_FORMAT 供统计。
