# 上线门禁和审批清单

状态由产品、研发、QA、运维及数据负责人共同裁定。每项提交日期、环境、版本、证据链接和签字。内部评分可辅助排期。

| 门禁 | 当前 | 可签字的条件 | 审批人建议 |
|---|---|---|---|
| G0 实验版本稳定 | 工程达到，未签字 | 冻结源码、合同与夹具哈希可验证。确定合成自动化和真实 API 档。已知事实与体验缺口登记 | 实验负责人、QA |
| G1 Staging Ready | BLOCKED | R01/R02/R05/R06/R08 关闭。正式合同和依赖经批准，独立 HTTPS，桌面/移动真实浏览器、北京 Flash、隔离与异常矩阵通过 | G07/G08/G09、G11/G12、G13、G15 |
| G2 Controlled Pilot Ready | BLOCKED | G1 通过，R03/R04/R07/R09/R10/R12/R13 关闭。监护人、供应商、法务、前端告知、人工接管、预算、源站保护和回滚均有回执。批准范围、预算、数据期限 | 产品、监护流程及数据负责人、QA、运维 |
| G3 Production Ready | BLOCKED | G2 通过，R11 关闭。批准的试运行周期和人群达标，零未解决 P0/P1。明确值班、告警、回滚和删除，负责人正式签字 | 产品、QA、安全/法务、运维、发布负责人 |

### 执行清单

- [ ] 合同已会签，旧客户端及 TTS/报告仍可读。版本和功能名单已复核。
- [ ] 发布号、镜像 digest、固定 Flash 模型及 Prompt SHA、夹具、配额、供应商地域可追踪。
- [ ] 越权、请求起止和撤销、未读泄露、危险建议均零关键失败，已有风险逐张关闭。
- [ ] 正常和异常、回翻/暂停/刷新、语音和并发都完成目标环境真机验收。
- [ ] 浏览器和 API P50/P95 分离，故障回退率、账单和完整试运行周期达约定标准。
- [ ] 数据告知、监护授权、撤回和删除按测试证据通过。供应商条款和地域路径已签。
- [ ] 停用开关、镜像回退、备份或迁移恢复、运行中 Session 均有独立演练。
- [ ] 事故联系人、阈值、审批时间段、告警渠道与公开说明已确认。

安全事故、仍可访问的撤回数据、儿童数据错发、关键事实错误、意外费用、可重复的回滚失败均暂停开放。触发即执行 [回滚](deployment-and-rollback.md)，由审批人批准复开。

## 切换审查增项

- [ ] Gate 1、Gate 2、Gate 3 分别签字，完成数据库兼容、会话状态、权限、异常和镜像回滚测试。
- [ ] 发版责任人记录切换时刻和旧版最后接收新会话的回执，抽查所有新会话绑定 2.0。
- [ ] 核验旧会话排空、旧模型最后一次调用、观察周期、删除范围和 2.0 回滚目标。 [退役条件](deployment-and-rollback.md)
