### 执行清单

- [ ] 合同已会签，旧客户端及 TTS/报告仍可读。版本和功能名单已复核。
- [ ] 发布号、镜像 digest、固定 Flash 模型及 Prompt SHA、夹具、配额、供应商地域可追踪。
- [ ] 越权、请求起止和撤销、未读泄露、危险建议均零关键失败，已有风险逐张关闭。
- [ ] 正常和异常、回翻/暂停/刷新、语音和并发都完成目标环境真机验收。
- [ ] 浏览器和 API P50/P95 分离，故障回退率、账单和完整试运行周期达约定标准。
- [ ] 数据告知、监护授权、撤回和删除按测试证据通过。供应商条款和地域路径已签。
- [ ] 停用开关、镜像回退、备份或迁移恢复、运行中 Session 均有独立演练。
- [ ] 事故联系人、阈值、审批时间段、告警渠道与公开说明已确认。

安全事故、仍可访问的撤回数据、儿童数据错发、关键事实错误、意外费用、可重复的回滚失败均暂停开放。触发即执行 [回滚](deployment-and-rollback.md)，由审批人批准复开。

## 最终审查复核项

- [ ] 在获批北京合成环境用实际用量验证输入上界、输出限制、费用估算与缺量留账。实时估算和供应商账单分别留证，完成偏差复核和告警演练。
- [ ] 独立审查多语姓名、学校和地址等非结构化输入，复核脱敏在请求、持久化、日志和撤回路径的覆盖。Gate 2 签字前继续仅用合成样例。
- [ ] 针对人物、属性、对象、动机、未读页和想象来源完成人工事实核验。合成正反例用于回归，真实模型质量由获批环境和双人审查确认。
- [ ] Gate 3 核对实际 Pilot 周期、事故演练与各项真实证据，完成正式签字。
