- - # G05 Agent 降级与异常处理契约
  
    本文档冻结 Agent 模块在遇到异常时的返回规范，所有返回值必须严格符合 `backend/app/schemas/agent.py` 中的 `AgentResult` 定义。
  
    ## 1. 超时（Timeout）
    - **触发条件**：模型调用超过 20 秒。
    - **处理逻辑**：模型适配器捕获超时，返回 `ModelGenerateResult(success=False, error_code="TIMEOUT", text="")`。引导工作流不得直接报错，需返回预设的兜底问句。
    - **返回结果**：
      - `status`: "FALLBACK"
      - `strategyType`: "TIMEOUT_FALLBACK"
      - `outputText`: "我们先看看画面上有什么吧？" (根据当前年龄段/上下文返回预设安全语句)
  
    ## 2. 无可用知识（No Knowledge）
    - **触发条件**：知识检索模块返回 `has_results=False`。
    - **处理逻辑**：引导工作流不强行让大模型生成，直接使用通用问题模板。
    - **返回结果**：
      - `status`: "FALLBACK"
      - `strategyType`: "NO_KNOWLEDGE_FALLBACK"
      - `outputText`: "这个故事里，你最喜欢谁呀？"
  
    ## 3. 触发安全规则（Blocked）
    - **触发条件**：用户输入命中 `KN-SAFE` 系列知识规则，或模型输出违规。
    - **处理逻辑**：中断大模型调用，直接返回安全拦截话术。
    - **返回结果**：
      - `status`: "BLOCKED"
      - `strategyType`: "SAFETY_BLOCK"
      - `outputText`: "这个问题我们请爸爸妈妈来一起说好吗？"
  
    ## 4. 主动跳过（Skip）
    - **触发条件**：前端发送 `feedback="SKIPPED"`。
    - **处理逻辑**：不调用检索模块，不调用大模型。
    - **返回结果**：
      - `status`: "FALLBACK"
      - `strategyType`: "SKIP"
      - `outputText`: ""

## API-017 的页面与反馈

首次提问使用当前页的已发布正文、档案年龄和绘本主题。理解反馈依据当前页最近一道可展示的问题，包括首次提问和随后已保存的追问。只有输出非空且可展示的结果能成为下一次反馈的依据。首题生成期间也可提交跳过。跳过先保存时递增修订号，迟到的提问返回 409。

服务端用当前页的短引文和对应反馈的问句生成候选项。模型可以选中候选原句，也可以用简短问句表达观察、行动或感受等意图。儿童端展示选中的本地候选问句。诊断、索取隐私及无法识别的输出会触发家长接管。成功事件保存实际进入提示词的知识来源。

儿童模式使用能按“是／不是／不知道”作答的问句，已审核的选项随题保存。无知识时返回“你喜欢这一页吗？”，超时时返回“你想再看看这一页吗？”。家长共读沿用开放问句。

适配器返回 `TIMEOUT` 时生成安全回退。未配置模型、鉴权失败、限流等 `API_ERROR` 由 API-017 返回 503 `DEPENDENCY_UNAVAILABLE`。同一事件键重放已记录的失败，不再调用模型。阅读进度保持原值，可以继续阅读或直接跳过。
