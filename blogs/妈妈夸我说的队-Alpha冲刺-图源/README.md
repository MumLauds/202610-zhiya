# 冲刺博客图源说明

博客《妈妈夸我说的队-Alpha冲刺.md》同时包含冲刺计划与总结，共使用 14 张图：1 张团队二创形象 + 11 张演示/Vlog 截图 + 2 张答辩 PPT 图表。
截图从团队自己录制的演示视频与 Vlog 中抽帧，图表取自答辩 PPT，没有使用设计稿或 Mock 图。

抽帧方式：Swift + AVFoundation（`AVAssetImageGenerator`），按固定间隔取帧后人工挑选；手机端截图从录屏中裁出中间的应用列（约 708×1590），桌面端保留整屏后按宽度缩放。PPT 图表为整页截图，缩到 1600px 宽。

## 使用说明

- 正文里图 4–图 14 仍指向博客园图床；图 2、图 3 是本地相对路径，发布前需要把这两张一并上传到博客园并替换地址。
- 正文用 `<img width="..." style="...max-width:100%">` 控制显示尺寸：桌面与图表 800px、手机 320px、Vlog 600px；若编辑器过滤样式，`width` 属性仍会生效。
- 手机端截图保留了录屏时的少量界面提示（如"实机""进度模拟"），这是产品真实状态，没有修图。
- 如需重新截取，视频可用 `ffmpeg -ss <秒> -i <视频> -frames:v 1 out.png` 抽帧；PPT 图可直接从第 5、6 页导出。
