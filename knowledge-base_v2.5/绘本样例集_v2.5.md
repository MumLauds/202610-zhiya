## 5. 与库表、接口的映射

以下映射依据《知芽数据库设计说明书》v1.1。家长私有绘本使用 `source_type='ORIGINAL'`，其 `owner_guardian_id` 必须关联所属家长账号。

| 本文数据 | 库表 | 字段示例 |
|---|---|---|
| 绘本本体 | `storybooks` | `id` 为整数主键，B-008 等为资料编号。本批团队绘本供公共书库使用，`source_type='LIBRARY'`，`owner_guardian_id=NULL`，填写 `created_at`。 |
| 绘本版本 | `story_versions` | `id` 为整数版本 ID，`storybook_id` 关联本体，`version_no` 为版本号。书名、AGE、THM、来源和授权分别映射至 `title`、`age_min` / `age_max`、`topics_json`、`source_ref`、`license_note`。本批为线性剧情，`branching=0`。 |
| 分页数据 | `story_pages` | 主键为 `(version_id, page_no)`，正文对应 `body_text`，配图资源键对应 `image_ref`，可选字段为 `audio_ref`、`image_license_note`。线性剧情的 `default_next_page_number` 指向同版本的下一页，结局页为空。 |
| 剧情分支 | `story_branches` | 有实际跳页选择时才记录 `id`、`version_id`、`from_page_no`、`next_page_no`、`choice_label`、`review_status`。起点与终点属于同一版本。剧情分支验收需另提供明确的跳页选项。 |
| 画面描述、互动提示、互动引导示例、ABL、DIF | 设计资料 | 画面描述用于制作插图。互动引导用于当前页的追问、提示或降级，沿用页面原有后继。 |
| 封面资产 | 独立资源映射 | 通过 `data/seed/cover_mapping.json` 将样例编号、整数绘本 ID 与封面路径关联。 |

接口 JSON 的 `storybookId` 对应 `storybooks.id`，`storyVersionId` 对应 `story_versions.id`。页面的 `pageNumber`、`text`、`imageRef`、`defaultNextPageNumber` 分别对应 `story_pages` 的 `page_no`、`body_text`、`image_ref`、`default_next_page_number`。
