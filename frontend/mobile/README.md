# 移动阅读端

在 `frontend/` 启动 Vite，打开 `/mobile.html`。桌面家长端与移动端共用同域后端及登录 Cookie。离线演示可以直接双击 `frontend/html-review/index.html`，保留相邻的 `../public/demo/` 媒体目录。

## 演示与实机

本地演示模式使用内置绘本、拼音及页面音频，朗读高亮按播放进度模拟。演示书架、收藏和演示阅读记录保存在本机。切换到“实机”后，按姓名选择儿童档案，再从首页或绘本馆选择一本书开始共读。书目来自 API-008，正文和配图来自 API-009。「我的」显示真实儿童档案，「原创故事」可进入家长端创作工坊。

从成长记录继续未完成的阅读，或查看已完成的阅读小结。成长记录按页读取 API-012，阅读器通过 API-013 确认会话绑定的绘本和当前页。普通返回保留已提交进度，“完成阅读”才通过 API-019 结束会话。

## 阅读与互动

- 开始、翻页和作答经 API-015 写入。儿童模式使用 API-013 或 API-017 返回的当页审核选项；家长共读支持文字和录音确认。通过上一页、下一页按实际访问顺序回看，同一书页的多次访问分别保留。回到最后一次访问后可继续提问和作答。
- 共读提问和理解程度反馈使用 API-017。录音通过 API-022 转写，家长可以修订或手动输入，再把实际文本作为 `ANSWER` 提交。页面及互动音频分别依据当前页或有效的互动事件调用 API-023，并通过 API-024 播放。
- 写入结果不确定时先读取 API-013。页面需要人工核对时会显示对应按钮；若传输中断且服务器仍在原修订号，重试沿用原事件编号。创建会话的响应丢失时，从成长记录核对新会话。

生产构建和离线版生成命令见[前端说明](../README.md)。
