# 知芽 Web

Vue 3 + Vite 家长端前端，覆盖首页、绘本馆、绘本详情、软页共读、语音入口和儿童档案。

使用 Node.js 20.19+（20.x）、22.12+（22.x）或 24+：

```powershell
npm ci
npm run dev
```

开发地址为 http://127.0.0.1:5173，`/api` 请求代理至本地 FastAPI 的 8000 端口。用 `npm run build` 构建静态资源。

## 后端对齐

- `src/api/` 按 `docs/design/api-contract.md` 封装登录、儿童档案、绘本、阅读会话和语音接口，所有请求携带 Cookie，写请求读取 `zhiya_csrf` 并放入 `X-CSRF-Token`。
- 绘本列表通过 API-008 分页加载，家长可继续加载同一筛选条件下的绘本。详情读取 API-009。已加载绘本的详情返回 404 时，书架按原筛选重新加载第一页。直接开读（API-011）返回 404 时，先通过 API-004 核对儿童档案。若原档案已失效，保留已加载的书目和选中项，家长重新选择或添加档案后再开读。若档案仍有效，只在发起请求的书架上通过 API-008 重查书目。等待期间若家长切换了筛选条件，保留新书架及其选中项。重查失败时保留已加载的书目，家长可重试。后端没有可见的已发布绘本时，界面会明确标注并展示本地设计预览。
- 阅读会话使用 API-011、API-015、API-013 和 API-019，家长可在读到最后一页之前结束本次共读。提前结束后按本次实际访问顺序回看，包括经过分支访问的页面。到达最后一个已访问位置时，“下一页”不可用。翻页和结束按服务端 `revision` 与 `clientEventId` 提交。
- 语音识别和合成调用 API-022、API-023。API-022 返回 `reliable=false` 时，亲子阅读弹窗展示“待确认的转写”，家长可以修改并确认，也可以重新录音。麦克风被拒或浏览器不支持录音时，家长可以手动输入问题并通过同一流程确认。确认后的文字仅供本次查看，AI 问答另行接入。文字只在当前弹窗展示，关闭或换页时清除。
- 儿童档案删除使用 API-007，阅读记录删除使用 API-014；两者都有二次确认、错误反馈和关联状态刷新。
- 桌面家长端可使用 API-020 设置儿童模式时长与授权绘本范围，并通过 API-021 重新验证家长密码退出儿童模式。桌面端只提供授权与交接页，不实现手机端或 4.3C 硬件端儿童界面。
- 收藏、阅读计划和家长昵称暂无持久化接口，因此继续保存在本地，并在个人中心明确说明。

后端 Cookie 使用 `Secure`，浏览器凭据联调应使用 HTTPS；纯 HTTP 启动只适合查看本地预览和健康检查。

## PR #42 审查修复

- 录音只有点击“停止并识别”才上传；取消、翻页、退出和组件卸载会停止麦克风并丢弃录音。申请权限或识别结果迟到时不更新已经关闭的页面。
- 朗读保留真实播放器引用；暂停、取消生成、换页和离开会释放播放器并取消等待。后端朗读失败直接提示原因，不静默改用其他朗读方式。取消等待不代表已经到达服务端的语音任务一定停止。
- 前进按 `defaultNextPageNumber` 提交，进度写入串行执行。已读页可以只读回看，回看期间禁用依赖当前服务端快照的语音入口。409 后读取完整会话，文字和翻书组件同时回到确认页。
- 客户端断网、超时或收到 `REQUEST_IN_PROGRESS` 后先查询会话。无法确认时禁用新写入，用户确认后按 `Retry-After` 原样复用原请求。服务端明确返回 504 `REQUEST_OUTCOME_UNKNOWN` 时，旧键已终结。成功读取 API-013 后展示服务端进度，由用户决定是否再次开始、翻页或完成。
- API-009 返回 404 后，详情显示“绘本暂不可用”，并从当前书架移除该版本。阅读会话不可用时可直接返回绘本馆。
- 家长完成阅读后先看到已保存的事实摘要。`PENDING` 时点击“刷新小结”只读取 API-013，`READY` 展示最终小结，`FAILED` 保留事实摘要。
- 成长统计按会话 ID 汇总各页历史。“已完成/进行中会话”只统计这两种状态。读过的版本按实际有访问记录的版本去重，浏览页数按每次会话的已访问页数相加。
- 退出失败会提示“服务器会话可能仍有效”，不会声称退出成功；成功退出和重新登录会清理账号相关缓存及本地偏好，忽略上个账号的迟到响应。
- 登录、注册、档案保存等待真实 Promise 完成，期间防重复提交；保存失败保留表单。401、CSRF、409、429、503、504 提供对应提示，不自动重发语音或其他写请求。
- 内页按各自 `imageRef` 展示；缺图或加载失败显示占位。API 绘本不再套用预览书的作者、年龄、封面和问答。首页、绘本馆和详情区分公开已发布与本人已审核私有绘本。
- 理解程度按钮标明暂不可用；语音入口只做识别，本页尚未接入 G10 问答。
- 家长可在未开始的会话中选择 5～30 分钟并授权一组绘本版本进入儿童模式；进入后家长导航与档案不可见，桌面只显示受限交接页和家长解锁入口。

## PR #46 复审修复

- 启动、切回标签页或收到其他标签页的账号变动时，通过 API-004 核对身份。账号名或随会话轮换的 CSRF Cookie 变化时，先清除旧书架、阅读历史、小结和打开的表单，再加载当前家长的数据。
- 首次交接入口只向处于 `CREATED` 的 `PARENT_CHILD` 会话开放。API-020 成功后通过 API-004 核对本机身份。如果另一台设备已签发儿童授权，本机仍持家长凭证，阅读页显示“此会话已开启儿童模式”并保留家长视图。
- 浏览器内的标签页共享交接会话编号，用于定位交接页。阅读时限到期后仍可通过 API-021 验证家长密码。设备凭证已失效时，解锁接口会指引前端返回登录页。
- API-021 成功后先切换家长凭证并离开密码页。后续档案读取失败会显示独立错误和重新读取入口，不会要求再次解锁。
- API-020 或 API-021 的响应中断时，页面转入只读身份核对。API-004 确认家长后恢复家长空间，确认儿童后恢复受限交接。核对暂时失败时，页面提供“重新核对设备身份”。儿童阅读时限到期后仍可验证家长密码。
- 家长密码被拒、限流和服务不可用时，错误原因显示在解锁表单内。
- 成长记录展示 API-012 返回的全部可见会话。同一本书的不同阅读记录显示 `阅读记录 #编号`，删除确认框也包含该编号。
- 儿童档案卡片和删除确认框均显示档案编号。API-007 成功后立即关闭确认框，档案和阅读记录分别刷新，读取失败可单独重试。API-014 成功后，删除前发出的历史查询结果会被忽略。
- 删除响应中断时，先读取档案列表或分页读取可见阅读历史。确认档案已移除后，也会关闭该档案的编辑表单。阅读记录未出现在列表时，通过 API-013 的 `view=deletion-status` 核对它是否仍归当前家长。成长页保留待核对编号，已记录登录账号的标签页刷新后可继续。确认记录仍存在时，只有家长再次确认才发送删除请求。API-014 明确返回 `404 RESOURCE_NOT_FOUND` 时结束删除交互，独立刷新历史。
- 成长记录和个人中心首页只在完整历史读取成功后显示统计值。读取中显示“读取中”，失败显示“待更新”，重新读取后显示其余档案的实际数据。
- 交接页只在进入时可确认授权数量；刷新恢复时 API-013 不返回完整授权列表，因此省略无法核实的具体数量，避免把当前绘本误报为全部授权。
