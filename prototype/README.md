## 原型范围

- 用户端：首页、绘本馆、原创故事、成长记录、家长中心
- 阅读流程：绘本详情、亲子共读、AI 共读提示、阅读小结
- 绘本数据：20 本原创绘本、104 个页面文本
- 后台管理：工作台、绘本管理、版本审核、领域知识库、接口与权限

## 说明

原型使用 Figma 的页面跳转和交互状态展示产品流程。真实语音合成、自由文本搜索、数据库查询和动态内容生成由后续软件端实现。
