## 原型内容

移动端插件包含首页、绘本馆、原创故事、成长记录、家长中心、绘本详情、亲子共读、AI 共读、阅读小结和儿童模式等页面。

后台管理插件包含工作台、绘本管理、版本审核、领域知识库、接口与权限五个模块。

## 原型边界

Figma 用于展示页面结构、交互状态和业务规则。真实语音合成、数据库查询和动态内容生成由后续软件端实现。
