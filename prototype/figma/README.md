## Figma 插件

- `mobile-plugin/`：生成移动端用户原型、阅读页、搜索页和家长中心页面。
- `admin-plugin/`：生成工作台、绘本管理、版本审核、领域知识库和接口与权限页面。

后台 Figma 原型通过本地插件生成。后台 HTML 版本不在本 PR 范围内。
