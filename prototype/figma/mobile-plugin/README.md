# 知芽 Figma 插件 v2

## 重新导入

1. 在 Figma 桌面版中打开“知芽 · 手机端原型”。
2. 点击左上角 Figma 图标，打开 `Plugins`。
3. 选择 `Development` → `Import plugin from manifest...`。
4. 选择本目录中的 `manifest.json`。
5. 运行 `Plugins` → `Development` → `知芽移动端原型生成器 v2`。
