# 知芽绘本 · 桌面端个人中心原型

## Figma 原型

- [打开完整 Figma 文件](https://www.figma.com/design/CiA9OlCqX7BUmf6oZqd7XU/Untitled?node-id=1-26)
- Figma 页面名称：`05 个人中心 · Desktop`

## 页面范围

本次交付仅包含桌面端，统一使用 `1440×900` 画板：

1. 个人中心首页
2. 个人资料
3. 儿童档案
4. 我的书架
5. 成长记录
6. 阅读计划

## 设计说明

- 延续现有首页的奶油白、浅木色、柔和绿色和暖棕色。
- 顶部导航与现有首页保持一致，个人中心使用独立的左侧功能导航。
- 右侧内容区使用统一圆角卡片、柔和阴影和清楚的标题层级。
- 当前模块使用深绿色高亮，其他导航保持轻量。
- 书架与阅读计划中的绘本卡片沿用现有封面素材和阅读状态表达。
- 仅设计桌面端，不包含移动端适配稿。

## 原型交互

- 左侧六个导航项可切换到对应模块。
- 首页的“查看全部”“查看计划”“切换孩子”等入口连接到对应模块。
- 儿童档案支持新增、编辑和删除确认反馈。
- 个人资料保存、头像更换、阅读计划编辑等操作配置了反馈浮层。
- 书架支持分类入口、收藏状态反馈和绘本详情预览。
- 阅读趋势支持周/月切换反馈，计划日历支持月切换反馈。

## 数据说明

原型中的昵称、孩子档案、书架数量、阅读时长和阅读记录均为演示数据，仅用于表达页面结构与交互状态。正式开发时，这些数据应与账号、儿童档案、收藏、阅读历史及阅读计划接口共用同一数据源。
